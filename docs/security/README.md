# 0.11 RC 보안·오류 검사

2026-10-09. 소유한 로컬 소스와 격리된 게임 프로필을 검사했다. 실제 사용자의 저장, 계정, 운영 프로필에 공격 입력을 넣지 않았다. 이 기록은 지정한 검사 범위에 대한 결과이며 모든 취약점 부재를 보증하지 않는다.

## 발견과 수정

| ID | 심각도 | 발견·조치 |
| --- | --- | --- |
| DEP-01 | Critical 포함, 패키지 DB 기준 | 전체 의존성 감사에서 62건(critical 1/high 30/moderate 23/low 8)이 보고됐다. Next·React RSC·Vite와 해당 전이 의존성을 패치 버전으로 갱신했다. 실제 배포 경로의 악용 가능성을 모든 항목에서 재현한 것은 아니다. |
| D-01 | Medium · QA 저장 격리 | Windows junction을 통해 QA 경로가 운영 경로의 별칭이 되는 경우를 확인했다. 기존 부모와 쓰기 대상 자식의 실제 경로를 계산하고 준비 전후 다시 검사한다. 끊어진 링크도 거부한다. 격리 fixture의 관련 22개 회귀 검사가 통과했다. 같은 사용자 프로세스의 동시 경로 교체를 완전히 차단하는 보장은 아니다. |
| WEB-01 | Medium · 기록 보존 | 큰 플레이테스트 기록의 저장·내보내기·가져오기 한도를 UTF-8 2,000,000바이트로 통일했다. 큰 편집은 저장 전 상태로 복구하며 JSON 압축 출력과 CSV 초과 안내를 제공한다. 7개 단위 검사와 실제 오프라인 도구의 저장/복원/내보내기 UI 회귀가 통과했다. |
| GAME-01 | 기능 무결성 | 작업 파일을 모두 삭제한 뒤 남은 초안으로 검사되는 경로를 닫았다. 삭제 순서 6가지와 재시작을 검사했다. 가져오기 시 이전 편집 경로도 초기화한다. |

## 실행한 검사

- 제한된 JavaScript: host/global/prototype 탈출 22개, 실행·자료 한도 14개, 잘못된 저장 11개 등 격리 프로브 47개. getter 미실행·입력 보존·연속 보상 재검사 포함.
- 웹 UI: 잘못된 JSON과 16MiB 초과 파일 거부 후 기존 저장 보존, 이력의 HTML 문자열 미실행, 실제 iframe의 script·iframe·외부 URL 속성 제거와 CSP 확인. 반복문·전역·constructor 입력 거부 후 정상 풀이로 복귀했다.
- 미리보기 파싱: 현재 Chrome에서 가상의 loopback 이미지·iframe 요청 후보가 실제 발생하지 않았다. 모든 외부 요청을 중단할 테스트 라우트를 두었으며, 관측 요청과 차단 요청 모두 0건이었다. 다른 엔진의 동일 동작까지 검증한 것은 아니다.
- Electron: protocol 경로·IPC sender/frame/origin·네트워크/탐색·저장/백업·내보내기·Steam 실패 반환을 별도 단위/프로브로 검사했다. QA 실제경로 수정 후 최신 네이티브 전체 플레이, QA 패키지 실행, 기본 패키지와 파일 18개의 일치 및 보안 fuse 검사를 통과했다. 자세한 범위는 릴리스 QA 기록에 있다.
- 알려진 비밀 형식: 추적된 UTF-8 파일 363개에서 GitHub/OpenAI/AWS 키 및 private-key 시작 패턴을 검사해 일치 없음. 모든 비밀 형식을 포함하는 검사는 아니다. 값을 보고서에 출력하지 않았다.

## 의존성의 남은 경고

패치 후 `pnpm audit --prod`와 `desktop/npm audit`는 보고된 취약점 0건이다. **전체 개발 의존성 감사에는 High 1건이 남아 있다:** [braces GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm). 검사 당시 패치 버전이 없다. 경로는 ESLint와 Vinext의 빌드용 glob 처리이며, 게임의 가상 파일·저장·터미널 입력을 이 패키지에 전달하지 않는다. 상세 도달 경로 검토는 web-review.md에 기록한다. 새 수정 버전이 나오면 갱신과 빌드 재검사가 필요하다. 전체 audit가 0건이라고 표현하지 않는다.

## 남는 한계

오프라인 저장은 암호학적 인증이나 온라인 치트 방지를 제공하지 않는다. 외부 Node용 vm 예제는 신뢰하는 소스용이며 게임 플레이어 코드는 별도 AST 해석기에서 실행한다. 실제 Steam 업적/Cloud/계정·코드 서명·별도 PC·사람의 재미와 학습 성과는 이 감사의 완료 범위가 아니다. 원격 모의 침투, 외부 호스팅 사업자 내부, OS 자체, 알려지지 않은 취약점은 검사하지 않았다.
