# Steam 출시 시작 — 2026-10-10 KST

현재 목표는 **새 게임 등록 → 상점 심사 → 출시 예정 페이지 공개**다. 정식 판매일은 아직 예약하지 않는다. 이 문서는 앞선 출시 계획의 현재 실행 상태를 갱신한다.

## 직접 확인한 상태

- 로그인된 Steamworks의 All Applications에 `Veins of the Sleeping Moon (5336990)`만 표시된다. 이 게임의 앱 항목은 없고, 새 앱 등록 크레딧은 0개다. 다른 게임의 ID·설정은 변경하지 않았다.
- `Pay Steam Direct Fee`를 누르면 Steam 스토어의 별도 로그인 화면으로 연결된다. 결제나 약관 동의를 수행하지 않았다. 로그인 URL의 인증 매개변수는 문서나 저장소에 보존하지 않는다.
- 공개 게임 주소: https://code.yeolmaeapps.kr/ . 소개: https://code.yeolmaeapps.kr/about . Steam 실제 판매 시작 전까지 현재 전체 웹판을 유지한다.
- 최신 게임 소스는 `16c8fabd5e64665f9932581b671ada3211a81f47`, 0.13.2-rc.0. Windows 후보 위치는 `D:/코딩게임/출시자료/0.13.2-게임반응-04/CODE-SHIFT-win32-x64`이며 `steam-config.json`의 AppID는 null이다.
- 자동 검사: 게임 247개, 네이티브 31개, 3언어 브라우저·보안 검사, 실제 Electron 카페 3장·후속 의뢰 18개·최종 엔딩·저장 복원 통과. 세부 결과는 [게임 반응 QA](../QA-TECHSTUDIO-FEEDBACK.md).
- 인간 초보자·경험자의 재미와 이해, 원어민 감수, 별도 PC 최소 사양, 실제 Steam 설치·업적·Cloud는 아직 미검증이다. 자동 검사 수를 출시 완성도나 사람 검증으로 바꾸어 말하지 않는다.

## 이번에 준비한 자료

- 최신 게임 화면을 1920×1080으로 14장 캡처했다. 우선순위 7장은 고객 문제 → 직접 코드 수정 → 수정 결과 → 의뢰 지도 → 보조 모니터 → 개인 프로젝트 검색/분류 → 바탕화면이다. 게임 외부 광고 문구를 합성하지 않았다.
- 촬영은 기존 UI 플레이로 얻은 카페 완료 저장을 화면에서 가져온 후, 12개 선택 의뢰와 개인 프로젝트를 실제 UI로 해결했다. `output/steam-launch-20261010/capture/capture-evidence.json`에 소스·저장 해시, 뷰포트, 보상·구매, 오류 0개가 기록되어 있다. `raw.webm`은 감사용 원본이며 새 편집 홍보영상이 아니다.
- 기존 최신 KO/EN/JA 30초 가로 영상과 KO 세로 영상, 음악 고지, 한국어·영어 썸네일, 상점 문구와 콘텐츠 설문, 플레이테스트 기록 도구를 별도 출시 시작 폴더에 모은다.
- 모든 자료는 **미제출 후보**다. 게임명은 확정 전까지 기존 CODE:SHIFT 가제를 사용한다. 한국 정가 11,000원과 출시 첫 7일 20% 할인(8,800원)은 사용자 확정 사항이다. 할인 선택은 2026-10-10 명시적 응답으로 확인했으며, Steam에는 아직 적용하거나 예약하지 않았다.
- 최종 게임명에 맞춘 Steam 캡슐·라이브러리 이미지가 필요하다. 기존 홍보 썸네일의 문구를 Steam 캡슐에 그대로 사용하지 않는다.

## 일정 조건

2026-10-10 공식 문서를 재조회했다. 앱 등록비는 앱당 **US$100 상당**, 해당 세금이 적용될 수 있으며 실제 결제 화면의 통화·총액이 기준이다. 오늘 결제가 완료됐다고 가정하지 않는다.

Onboarding 문서는 첫 몇 타이틀에 대해 **결제 후 21일 대기**를 안내한다. Coming Soon은 **공개 후 최소 14일**이다. 상점과 제품 빌드 심사는 각각 통상 3~5영업일, 최소 7영업일의 여유를 권한다. 실제 계정의 해제일·심사 결과가 최종 기준이다.

판매 가능일은 `max(계정의 결제 대기 해제일, Coming Soon 공개일+14일, 상점/제품 승인일, 품질 확인 완료일)` 이후다. 이 조건들은 일부 병행할 수 있고, 심사 지연·수정이 생기면 늦어진다. 결제·공개가 아직 이루어지지 않아 출시일을 확정하지 않는다.

현재 공식 출시 할인은 **7~14일, 최대 40%**다. Steam은 보통 10~15%를 제안한다. 사용자는 2026-10-10 **출시 첫 7일 20% 할인·8,800원**을 선택했다. 출시일은 미정이며 실제 Steam 할인은 아직 적용·예약하지 않았다. 과거의 50% 제안은 이번 20% 결정으로 대체되었다.

## 실제 플레이 확인

- 초보자 3~5명, 코딩 경험자 2명으로 소규모 관찰을 진행한다. 모집·참여·결과는 아직 없다. 사용자 본인의 플레이와 독립 참가자를 구분한다.
- 초보자는 새 프로필에서 20~30분. 첫 목표 찾기, 수정과 결과의 관계 설명, 외부 도움 없이 다음 의뢰 찾기를 관찰한다. 막힌 화면·행동·힌트 사용을 익명 기록한다.
- 경험자는 직접 작업 모드에서 터미널과 다른 함수 풀이를 사용하고, 지원하지 않는 명령·문법 때문에 혼란스러운 지점을 기록한다. 적어도 한 의뢰를 다른 해법으로 해결했는지 확인한다.
- 출시 전 재검토 조건: 저장 손실·진행 막힘이 남으면 수정 후 재시험. 두 명 이상이 같은 첫 진입 지점에서 멈추면 해당 안내를 고친다. 숫자는 내부 판단 기준이며 학습 효과의 통계적 증거가 아니다.
- 기록 도구와 안내는 [플레이테스트](../playtest/README.md)를 사용한다. 초대 메시지는 발송하지 않았다.
