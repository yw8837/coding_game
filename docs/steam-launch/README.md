현재 계정 확인 결과는 메인 작업의 2026-10-09 Steamworks 화면 확인에 따른 **게임 앱 미등록 / 사용 가능한 앱 등록 크레딧 0개**다. AppID와 Windows depot ID는 미발급이다. 다른 앱 `5336990`이나 SDK 예제 `480`을 이 게임에 사용하지 않는다. 이 문서 작성자가 계정 화면을 독립 재확인한 것으로 표현하지 않는다.

현재 구현은 카페 3장, 동네 의뢰 18개, 선택 연습 6개, 작업실 구매, 첫 프로젝트 1.0.0 배포와 답장에 따른 엔딩이다. 한국어·영어·일본어 및 언어 자동 선택, Windows x64 오프라인 패키지와 로컬 저장 경계가 있다. 실제 Steam 실행·업적·Cloud, 별도 저사양 PC, 코딩 비경험자 인간 플레이테스트는 아직 확인되지 않았다. 메인 담당 보고로 0.11 Code Lab 12개와 제한된 JavaScript 인터프리터는 구현되었고 단위·타입 검사를 통과했다. 상점 초안에 정확한 범위로 포함했으며 최종 브라우저·패키지·언어·저장 검증 후 공개한다. 해당 빌드에 Code Lab을 넣지 않을 경우 추가 단락을 삭제한다.

42초 실제 플레이 영상 4개와 1920×1080 스크린샷 14개는 `output/trailer-0.10/`에 있다. 촬영 게임 커밋은 `969f78b`이며 Code Lab은 포함하지 않는다. 후반 장면의 기존 UI-earned 저장 파일 사용, 음악·아트·폰트 출처와 검토 한계는 해당 폴더 README 및 evidence 파일을 따른다.
