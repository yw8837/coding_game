# Steam 출시 자료 초안

기준일: 2026-10-10. CODE:SHIFT는 가제다. 이 폴더는 로컬 검토 자료이며 Steamworks에 등록·업로드·게시한 기록이 아니다.

사용자가 정한 한국 정가는 **11,000원**이며 아직 Steam에 적용하지 않았다. 출시 할인은 최종 선택 대기 중이다. 첫 7일 **20% · 8,800원은 현재 추천**, **10% · 9,900원은 이전안**, **40% · 6,600원은 출시 할인 최대 한도안**이며 모두 미적용이다. 50%는 Steam 출시 할인 최대 40%를 초과한다. 현재 웹판은 전체 무료이며, **Steam에서 실제 구매가 가능해진 뒤 카페 입문 3장까지만 무료 홍보 데모로 남길 계획**이다. 유료판에는 후속 의뢰 18개, 선택 연습 6개, Code Lab 12개와 최종 프로젝트를 포함한 전체 캠페인을 제공한다. 웹 제한은 아직 구현하지 않았다. 가격 판단과 계산은 [가격 문서](../pricing-2026-10.md)를 따른다.

현재 계정 확인 결과는 메인 작업의 2026-10-09 Steamworks 화면 확인에 따른 **게임 앱 미등록 / 사용 가능한 앱 등록 크레딧 0개**다. AppID와 Windows depot ID는 미발급이다. 다른 앱 `5336990`이나 SDK 예제 `480`을 이 게임에 사용하지 않는다. 이 문서 작성자가 계정 화면을 독립 재확인한 것으로 표현하지 않는다.

0.12 출시 후보의 콘텐츠는 카페 3장, 동네 의뢰 18개, 선택 연습 6개, 작업실 구매, 첫 프로젝트 1.0.0 배포와 답장에 따른 엔딩이다. 한국어·영어·일본어 및 언어 자동 선택, Windows x64 오프라인 패키지와 로컬 저장 경계가 있다. 실제 Steam 실행·업적·Cloud, 별도 저사양 PC, 코딩 비경험자 인간 플레이테스트는 아직 확인되지 않았다. 0.11에서 구현한 Code Lab 12개와 제한된 JavaScript 인터프리터도 포함한다. 상점 초안에 해당 범위를 기재했으며 최종 브라우저·패키지·언어·저장 검증 결과와 대조한 뒤 공개한다. 해당 빌드에 Code Lab을 넣지 않을 경우 추가 단락을 삭제한다.

카페의 함께 배우기는 간판 이름 직접 입력, 너비 슬라이더, 계산 연산자 직접 입력, 메뉴 주소 입력과 주문 보관 설정을 사용한다. 후속 18개 의뢰에서는 고객 상황을 골라 현재 파일의 실제 평가 결과를 실행하고, 값을 직접 입력하거나 짧은 식·코드를 수정한다. 첫 여섯 의뢰도 직접 입력하며 수동 도움에서 고른 예시는 입력 초안만 채운다. 적용·검사·전달은 플레이어가 수행한다. 파일 또는 상황이 달라지면 이전 실행 결과는 오래됐다고 표시되며, 상황 실험 자체는 보상·완료를 지급하지 않는다. 직접 작업은 후속 의뢰와 최종 프로젝트의 전체 코드 편집을 기본으로 하고 한 부분씩 고치기로 전환할 수 있다. 힌트와 예시는 직접 열며 오류가 자동으로 열지 않는다. 고객 답장 선택은 유지한다. 바탕화면은 무료 기본 블루, 햇살 해변 90cr, 초록 정원 90cr, 오피스텔 작업실 180cr의 실제 이미지 네 종류를 지원한다.

최신 홍보영상은 `output/trailer-rebuild/final/`의 30초 KO/EN/JA 가로 영상과 KO 세로 영상이다. 0.11.1 한국어 실제 UI를 자동 촬영하고, 후반에는 기존 UI 플레이로 얻은 18개 의뢰 완료 저장을 화면에서 가져와 첫 앱 배포를 촬영했다. 0.12의 새 고객 상황 실행 화면과 첫 여섯 의뢰의 직접 입력, Code Lab은 영상에 포함하지 않는다. 기존 30초 촬영본을 유지하고 새 UI 검증은 별도 QA 기록으로 남긴다. 음악은 Kevin MacLeod의 **Realizer**, CC BY 4.0이며 영상과 함께 `ATTRIBUTION.txt`를 제공한다. 크레딧에는 원본 출처, 구간 편집과 125→128 BPM 템포 조정을 기재한다. 촬영·편집 증거와 파일별 QA JSON을 함께 검토하며 자동 디코드 검사를 사람의 시청·청음으로 표현하지 않는다.

기존 42초 영상과 스크린샷은 `output/archive/trailers-before-rebuild-20261009/trailer-0.10/`에 보존한다. 현재 출시 자료에는 최신 결과를 사용한다.
