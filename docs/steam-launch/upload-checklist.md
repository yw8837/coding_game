# Steam 등록·업로드·공개 체크리스트

2026-10-10. 로컬 준비용. 결제, 앱 등록, SteamCMD 업로드, Coming Soon 게시와 출시는 실행하지 않았다. 2026-10-09 메인 담당이 확인한 대시보드는 게임 앱 미등록·사용 가능 크레딧0이다. 기존 다른 게임 `5336990`은 사용하지 않는다.

## 1. 계정과 실제 식별자

- [ ] 소유자가 계약, 신원, 세무, 은행 정보와 권한을 확인한다. 비밀 정보를 저장소에 넣지 않는다.
- [ ] 새 게임용 Steam Direct 크레딧을 구매한다. 공식 비용은 앱마다 미화100달러 상당이며 해당 세금은 별도다. Steam 지갑 자금은 사용할 수 없다.
- [ ] 비용을 지불한 본인이 크레딧을 사용해 이 게임의 새 AppID를 만든다. Windows depot ID와 패키지 연결도 대시보드에서 확인한다.
- [ ] 최종 이름과 한국·미국·일본 상표, Steam 유사 제목을 검토한다. CODE:SHIFT는 가제이며 이름 사용 가능성은 미확정이다.
- [ ] `desktop/steam-config.json` 등 실제 설정은 새 AppID를 사용한다. 다른 게임 `5336990`, 예제 `480`, 추측한 ID를 사용하지 않는다.

## 2. 제품과 사람의 검증

- [ ] 코딩 비경험자 인간 플레이테스트를 진행한다. 빈 바탕화면→메시지→간판 이름 직접 입력→너비 슬라이더 조절→계산 연산자 직접 입력→메뉴 주소 직접 입력→주문 저장 설정→동네 의뢰→프로젝트 검사·1.0 배포 흐름을 이해하는지, 막힘과 재미를 기록한다. 각 변경의 저장과 화면·손님 주문·API 검사 결과를 확인하고, 힌트는 플레이어가 수동으로 여는지 확인한다. 뒤의 18개 의뢰에 남아 있는 선택·빈칸·짧은 식 입력과 손님 답장 선택도 검증한다. 자동 완주는 학습 성과 증거가 아니다.
- [ ] 실제 배경 4종인 기본 블루(무료), 햇살 해변(90cr), 초록 정원(90cr), 오피스텔 작업실(180cr)을 확인한다. 구매 시 잔액과 소유권 저장, 저장 복원, 이미 소유한 배경의 무료 재적용을 검사한다.
- [ ] 0.11 Code Lab 12개를 최종 브라우저 및 Windows 패키지에서 확인한다. 메뉴, 코드 편집, 입력별 검사, 정답/오답, 저장/복원, 3개 언어를 포함한다. 제한된 JS 퍼즐이며 일반 JS 실행기·실제 API/결제 서비스로 소개하지 않는다.
- [ ] 한국어·영어·일본어 원어민 문구 검토와 UI 잘림 확인을 한다. 음성 없는 현재 빌드는 Steam 언어 표에서 인터페이스·자막/텍스트를 정확히 선택하고 “Full Audio”를 체크하지 않는다.
- [ ] 실제 플레이 시간은 사람의 대표 플레이로 기록한다. 현 단계에서 6~8시간이나 업무 숙련 보장 문구를 사용하지 않는다.
- [ ] 최종 게임 이름, 버전, 커밋, 빌드 해시와 자산 출처를 함께 보존한다.

## 3. 가격과 요구사양

한국 기준 가격안은 **₩21,000**이다. 아직 Steam에 등록하거나 승인받은 가격이 아니다. 지역별 가격은 Steam 지역 도구와 시장을 검토해 별도 설정하고, 출시 할인과 날짜도 소유자가 결정한다. 앱 등록비 US$100은 게임 판매가와 별도 비용이다.

| 필드 | 현재 상태 | 등록 전 증거 |
| --- | --- | --- |
| 대상 플랫폼 | Windows x64 오프라인 RC 구현 | 실제 Steam 실행 패키지의 지원 OS 버전 확인 |
| OS 최소 버전 | 실측 미확정 | 해당 OS에서 설치·실행·저장·종료 검사 |
| CPU / RAM | 실측 미확정 | 저사양 별도 PC에서 부팅·대표 의뢰·엔딩 프레임/메모리 기록 |
| GPU / DirectX | 실측 미확정 | 실제 GPU/드라이버와 그래픽 경로 확인; 임의 DirectX 버전 기입 금지 |
| 저장 공간 | 최종 Steam 빌드 미확정 | 실제 depot 설치 크기 + 저장/업데이트 여유 측정 |
| 입력 / 화면 | 키보드·마우스 중심 | 작은 창/해상도와 CJK 글자 읽기 검사 |
| 인터넷 | 게임 플레이 오프라인 경로 구현 | Steam 초기 설치/인증 조건과 실제 오프라인 재실행 구분 |
| Linux / macOS / Steam Deck / 컨트롤러 | 검증되지 않음 | 전용 패키지·입력·휴대 화면을 별도 검증 후 표시 |

최소/권장 사양칸에 위 “미확정”을 출시용 값으로 붙여 넣지 않는다. 개발 PC에서 한 번 동작했다는 사실이나 Electron의 기술 하한을 게임의 최소 사양으로 쓰지 않는다.

## 4. 상점과 콘텐츠 설문

- [ ] `store-copy.json`의 KO/EN/JA short/long을 실제 출시 범위와 대조한다. Code Lab 미동봉 시 해당 단락을 제거한다. 출시 이후 계획은 명확히 구분한다.
- [ ] [capsule-plan.md](capsule-plan.md)에 따른 크기와 읽을 수 있는 최종 로고를 준비한다. 승인 아트의 자르기·배치만 계획된 상태이며 캡슐 파일은 미생성이다.
- [ ] 현재 빌드에서 실제 UI 대표 플레이 스크린샷 5장 이상을 새로 캡처하고 선택한다. 추천 장면은 간판 직접 입력과 너비 슬라이더, 저장한 `*` 연산자의 주문 합계 13,500원, 메뉴 주소와 API 검사, 배경 구매, 프로젝트 코드·미리보기와 최종 배포다. 글자와 결과를 읽을 수 있는지 확인하고, 메시지·편지처럼 텍스트 비중이 높은 장면만으로 대표 세트를 채우지 않는다. 보관된 0.10 PNG를 현재 빌드의 증거로 간주하지 않는다.
- [ ] `output/trailer-rebuild/final/`의 30초 영상 `codeshift-ko.mp4`, `codeshift-en.mp4`, `codeshift-ja.mp4`(1920×1080)와 `codeshift-ko-vertical.mp4`를 검토한다. 게임 화면은 실제 한국어 UI이며 새 자동 조작 캡처를 사용했다. 후반부에는 이전 실제 UI 플레이로 얻은 저장을 화면에서 가져온 뒤 최종 앱을 수정·배포한 장면이 포함된다. `output/trailer-rebuild/capture-evidence.json`과 파일별 QA JSON에 연결해 확인한다. Code Lab은 현재 영상에 포함되지 않는다. 자동 디코딩 검사는 사람의 전체 재생·헤드폰/스피커 청취를 대신하지 않으며, 사람의 청취는 아직 수행하지 않았다.
- [ ] 영상 음악 “Realizer”의 Kevin MacLeod 출처, CC BY 4.0 라이선스와 `output/trailer-rebuild/final/ATTRIBUTION.txt`의 저작자·라이선스 링크·원본 링크·편집 내역을 확인하고 업로드 시 고지한다. 편집은 발췌, 125→128BPM 템포 조절(피치 유지), 영상용 믹싱이다. 이전 42초 영상은 `output/archive/trailers-before-rebuild-20261009/trailer-0.10/`에 보관되어 있으며 현재 업로드 검토에는 최신 30초 결과물을 사용한다.
- [ ] `content-survey.md` 초안을 최종 콘텐츠와 대조해 정확한 설문에 답한다. 사전 생성 AI 아트·문구·번역을 공개한다. 현재 live AI는 없다.
- [ ] 국가별 연령 등급과 설문 결과를 확인한다. 15세 전후 타깃은 기획 타깃이며 공식 “15세 등급”이 아니다.
- [ ] 지원 연락처, 개발자/퍼블리셔명, 장르·태그, 언어, 사양, 가격과 출시 표시를 작성한다. 후보 태그는 Simulation / Programming / Puzzle / Singleplayer이며 현재 내용에 맞는 실제 Steam 태그를 선택한다.
- [ ] Steam 업적과 Cloud 체크박스는 실제 설정 및 실행 검증 완료 후 선택한다. 로컬 저장이 있다고 Cloud로 표시하지 않는다.
- [ ] 상점 심사를 요청하고 필요 수정에 대응한다. 통상3~5영업일, 최소7영업일 여유를 계획한다.
- [ ] 승인 후 소유자가 “Post as Coming Soon”을 실행한다. 공개된 Coming Soon 페이지를 출시 전 최소2주 유지한다.

## 5. 실제 Steam 빌드와 제출

- [ ] 실제 새 AppID로 Steam 패키지를 재빌드한다. 일반 오프라인 패키지나 QA 패키지의 설정만 바꿔 사용하지 않는다.
- [ ] `desktop/steam/README.md`의 로컬 preflight를 통과한다. AppID/depot 소유권, SDK 재배포 조건과 제3자 라이선스, 네이티브 x64 파일을 확인한다.
- [ ] Steamworks Windows 실행 설정을 실제 실행 파일 `CODE-SHIFT.exe`에 연결한다. 최종 이름 변경 시 실제 경로도 함께 확인한다.
- [ ] QA-NOT-FOR-DISTRIBUTION, 테스트 저장, 비밀 파일, 개발용 `steam_appid.txt`를 depot에서 제외한다. production runtime이어야 한다.
- [ ] 9개 업적 API 이름·번역·아이콘을 등록하고 실제 Steam 계정에서 새 게임/기존 저장 복원/오프라인 후 복귀를 시험한다. 카탈로그는 `achievements.json`이다. 현재 실계정 업적은 검증되지 않았다.
- [ ] Cloud를 사용할 경우 업로드/다운로드/충돌/재설치/계정 전환을 실제로 확인한다. 설정 예시는 Cloud 활성화의 증거가 아니다.
- [ ] 별도 Windows PC에서 Steam 설치·실행·한/영/일 언어·오프라인·저장/백업 복구·정상 종료·업데이트 회귀를 확인한다.
- [ ] 소유자가 검토한 업로드 설정으로 SteamPipe 업로드를 실행하고 비공개 브랜치에서 검사한다. 현재 preflight VDF의 `Preview "1"`은 업로드가 아니며 `SetLive`도 없다.
- [ ] 상점 검토 뒤 근최종 제품 빌드 심사를 제출한다. 통상3~5영업일, 최소7영업일을 계획하고 수정 시간을 별도로 둔다.

## 6. 출시 일정의 하한과 최종 공개

2026-10-09 영어 공식 Onboarding 문서는 **첫 몇 타이틀에 대해 앱 등록비 지불 후21일 대기**를 명시한다. 과거30일 안내를 그대로 적용하지 않는다. 계정의 실제 해제일과 최신 문서를 최종 기준으로 확인한다. Coming Soon 최소2주와 상점·제품 심사는 별도 조건이며 가능한 작업은 병행할 수 있다.

공개 가능 시점은 계정에 표시된 앱 결제 대기 해제일, Coming Soon 공개일+14일, 상점·제품 심사 승인 및 모든 미완료 항목을 충족한 뒤다. 검토 소요시간은 보장된 출시 날짜가 아니므로 아직 날짜를 확정하지 않는다. 현재 결제·새 AppID·공개 페이지가 없어 계산할 실제 시작 날짜도 없다.

- [ ] 출시자 최종 승인 후 Steamworks 공개 버튼을 실행하고 실제 고객 계정에서 구매/설치/실행과 상점 현지화를 확인한다.

공식 근거와 원문 확인 날짜는 [official-sources.md](official-sources.md)를 따른다.
