# Steam 등록·업로드·공개 체크리스트

영상 최신 수정: [2026-10-10 홍보영상·음악 QA](../QA-trailer-polish-2026-10-10.md). 게임·Windows 패키지 검증은 기존 0.13.2 기록과 구분한다.

2026-10-10, 0.13.2 RC 기준의 로컬 준비용. 결제, 앱 등록, SteamCMD 업로드, Coming Soon 게시와 출시는 실행하지 않았다. 2026-10-09 메인 담당이 확인한 대시보드는 게임 앱 미등록·사용 가능 크레딧0이다. `5336990`은 다른 게임 Veins of Sleeping Moon의 ID이므로 사용하지 않는다. 아래 미완료 항목을 자동 QA 통과만으로 완료 표시하지 않는다.

## 1. 계정과 실제 식별자

- [ ] 소유자가 계약, 신원, 세무, 은행 정보와 권한을 확인한다. 비밀 정보를 저장소에 넣지 않는다.
- [ ] 새 게임용 Steam Direct 크레딧을 구매한다. 공식 비용은 앱마다 미화100달러 상당이며 해당 세금은 별도다. Steam 지갑 자금은 사용할 수 없다.
- [ ] 비용을 지불한 본인이 크레딧을 사용해 이 게임의 새 AppID를 만든다. Windows depot ID와 패키지 연결도 대시보드에서 확인한다.
- [ ] 최종 이름과 한국·미국·일본 상표, Steam 유사 제목을 검토한다. CODE:SHIFT는 가제이며 이름 사용 가능성은 미확정이다.
- [ ] `desktop/steam-config.json` 등 실제 설정은 새 AppID를 사용한다. 다른 게임 `5336990`, 예제 `480`, 추측한 ID를 사용하지 않는다.

## 2. 제품과 사람의 검증

현재 RC 자동 검증은 [0.13.2 QA](../QA-0.13.2-RC.md)와 연결된 버전·소스·실행 기록을 기준으로 확인한다. 이 체크리스트의 일관성 갱신은 최종 빌드·native·패키지·영상 검증 완료를 뜻하지 않는다.

- [ ] 코딩 비경험자 인간 플레이테스트를 진행한다. 카페 입문 3장→각 구역의 6개 중 4개씩 선택한 12개 의뢰→개인 프로젝트 검사·1.0 배포 흐름에서 이해·막힘·재미와 실제 시간을 기록한다. 변경의 저장과 결과, 수동 힌트 사용, 남은 선택 의뢰·고객 답장도 확인한다. 자동 완주는 이해·재미·학습 성과의 증거가 아니다.
- [ ] 최종 출시 후보의 새 플레이에서 선택 12/18 경로와 나머지 의뢰 재방문, 세 구역의 6개 전체 완료 업적, 기존 저장 호환을 대조한다. JavaScript 대안 5개(빵 가격·도서 대출·연락처 정리·배송 요금·행사 보고서)의 설정/함수 전환, 초안 유지·저장·다른 입력 실행·검사·전달을 확인한다.
- [ ] 개인 프로젝트의 장소 안내·행사 목록·포트폴리오, 직접 작성한 제목·설명·항목·분류, 검색·분류 필터, 색·목록/카드 배치와 문의 보관을 실제 최종 빌드에서 확인한다. 게임 안 배포와 실제 서비스/Steam 배포를 설명에서 구분한다.
- [ ] 실제 배경 4종인 기본 블루(무료), 햇살 해변(90cr), 초록 정원(90cr), 오피스텔 작업실(180cr)을 확인한다. 구매 시 잔액과 소유권 저장, 저장 복원, 이미 소유한 배경의 무료 재적용을 검사한다.
- [ ] 선택 Code Lab 12개를 최종 브라우저 및 Windows 패키지에서 확인한다. 메뉴, 코드 편집, 입력별 검사, 정답/오답, 저장/복원, 3개 언어를 포함한다. 제한된 JS 퍼즐이며 일반 JS 실행기·실제 API/결제 서비스나 높은 수준의 학습 성취를 보장하지 않는다.
- [ ] 한국어·영어·일본어 원어민 문구 검토와 UI 잘림 확인을 한다. 음성 없는 현재 빌드는 Steam 언어 표에서 인터페이스·자막/텍스트를 정확히 선택하고 “Full Audio”를 체크하지 않는다.
- [ ] 실제 플레이 시간은 사람의 대표 플레이로 기록한다. 현 단계에서 6~8시간이나 업무 숙련 보장 문구를 사용하지 않는다.
- [ ] 최종 게임 이름, 버전, 커밋, 빌드 해시와 자산 출처를 함께 보존한다.

## 3. 가격과 요구사양

정가는 **₩11,000**, 출시 할인은 **첫 7일 20%(8,800원)**로 2026-10-10 사용자 확정했다. Steam에는 아직 적용·예약하지 않았다. 공식 정책의 기록된 조건과 실제 계정의 최신 설정을 적용 전에 대조한다.

- [ ] Steam 본편 실제 구매 가능 후 공개 웹을 홍보 데모로 전환한다. 권장 범위는 카페 3장·OPEN. 기존 전체판 저장 보존·백업 내보내기·본편 가져오기, 실제 상점 링크를 확인한 뒤 적용한다. 그 전까지 현재 웹은 전체 무료로 유지하며 데모 제한은 미구현이다.

한국 기준 가격은 **₩11,000**이다. 아직 Steam에 등록하거나 승인받은 가격이 아니다. 지역별 가격은 Steam 지역 도구와 시장을 검토해 별도 설정한다. 출시 할인은 첫 7일 20%(8,800원)로 사용자 확정했으며, 실제 설정과 출시일은 미정이다. [가격 근거](../pricing-2026-10.md)를 참고한다. 앱 등록비 US$100은 게임 판매가와 별도 비용이다.

## 4. 상점과 콘텐츠 설문

- [ ] `store-copy.json`의 KO/EN/JA short/long을 실제 0.13.2 이후 최종 출시 범위와 대조한다. 18개 중 선택 12개 진행, JavaScript 대안 5개와 개인 프로젝트 수가 일치해야 한다. Code Lab 미동봉 시 해당 단락을 제거한다. 출시 이후 계획은 명확히 구분한다.
- [ ] [capsule-plan.md](capsule-plan.md)에 따른 크기와 읽을 수 있는 최종 로고를 준비한다. 승인 아트의 자르기·배치만 계획된 상태이며 캡슐 파일은 미생성이다.
- [ ] 최종 빌드에서 실제 UI 스크린샷 5장 이상을 새로 캡처·선택한다. 카페 문제와 변경 결과, 의뢰 선택, 직접 작성한 JavaScript와 입력별 결과, 개인 프로젝트 검색·분류와 배포를 포함한다. 글자와 결과를 읽을 수 있는지 확인하고 메시지·편지만으로 채우지 않는다. 오래된 0.10 PNG를 현재 빌드 증거로 간주하지 않는다.
- [ ] `output/trailer-polish/final/`의 30초 KO/EN/JA 가로와 KO 세로 공개 후보를 최종 빌드와 대조한다. **0.13.2 한국어 실제 UI** 촬영에 KO/EN/JA 편집 타이포그래피를 얹었으며 세 언어 UI 촬영본이 아니다. `output/trailer-polish/raw.webm`, `capture-evidence.json`, `edit/edl-current.json`의 UI-earned 카페 저장 가시적 가져오기, 촬영 중 12개 의뢰 해결과 직접 만든 포트폴리오의 게임 안 1.0.0 배포 근거를 확인한다. 중간 행동을 생략하고 시간을 조절한 몽타주이며 Code Lab 장면은 없다. 최종 자동 영상 QA는 위 0.13.2 QA 기록을 따르고 사람의 전체 재생·헤드폰/스피커 청취는 따로 진행한다. 사람의 청취는 미완료다. 0.11.1 영상은 `output/trailer-rebuild/final/`에 보관된 역사 자료다.
- [ ] 영상 음악 “Voxel Revolution”의 Kevin MacLeod 출처, CC BY 4.0 라이선스와 `output/trailer-polish/final/ATTRIBUTION.txt`의 저작자·라이선스 링크·원본 링크·편집 내역을 확인하고 실제 업로드 시 고지한다. 편집은 발췌, 122→128BPM 템포 조절(피치 유지), 영상용 믹싱이며 편집 효과음도 사용한다. 실제 게임 오디오 실시간 녹음으로 소개하지 않는다. 42초 0.10 및 30초 0.11.1 영상은 보관 자료이며 최종 영상이 바뀌면 실제 사용 내역으로 고지를 갱신한다.
- [ ] `content-survey.md` 초안을 최종 콘텐츠와 대조해 정확한 설문에 답한다. 사전 생성 AI 아트·문구·번역을 공개한다. 현재 live AI는 없다.

- [ ] 지원 연락처, 개발자/퍼블리셔명, 장르·태그, 언어, 사양, 가격과 출시 표시를 작성한다. 후보 태그는 Simulation / Programming / Puzzle / Singleplayer이며 현재 내용에 맞는 실제 Steam 태그를 선택한다.

## 5. 실제 Steam 빌드와 제출

- [ ] 실제 새 AppID로 Steam 패키지를 재빌드한다. 일반 오프라인 패키지나 QA 패키지의 설정만 바꿔 사용하지 않는다.
- [ ] `desktop/steam/README.md`의 로컬 preflight를 통과한다. AppID/depot 소유권, SDK 재배포 조건과 제3자 라이선스, 네이티브 x64 파일을 확인한다.
- [ ] Steamworks Windows 실행 설정을 실제 실행 파일 `CODE-SHIFT.exe`에 연결한다. 최종 이름 변경 시 실제 경로도 함께 확인한다.
- [ ] QA-NOT-FOR-DISTRIBUTION, 테스트 저장, 비밀 파일, 개발용 `steam_appid.txt`를 depot에서 제외한다. production runtime이어야 한다.
- [ ] 9개 업적 API 이름·번역·아이콘을 등록하고 실제 Steam 계정에서 새 게임/기존 저장 복원/오프라인 후 복귀를 시험한다. 카탈로그는 `achievements.json`이다. 현재 실계정 업적은 검증되지 않았다.
- [ ] Cloud를 사용할 경우 업로드/다운로드/충돌/재설치/계정 전환을 실제로 확인한다. 설정 예시는 Cloud 활성화의 증거가 아니다.
- [ ] 별도 Windows PC에서 Steam 설치·실행·한/영/일 언어·오프라인·저장/백업 복구·정상 종료·업데이트 회귀를 확인한다.
- [ ] 소유자가 검토한 업로드 설정으로 SteamPipe 업로드를 실행하고 비공개 브랜치에서 검사한다. 현재 preflight VDF의 `Preview "1"`은 업로드가 아니며 `SetLive`도 없다.
- [ ] 상점 검토 뒤 근최종 제품 빌드 심사를 제출한다. 통상3~5영업일, 최소7영업일을 계획하고 수정 시간을 별도로 둔다.

## 6. 출시 일정의 하한과 최종 공개

2026-10-09 영어 공식 Onboarding 문서는 **첫 몇 타이틀에 대해 앱 등록비 지불 후21일 대기**를 명시한다. 과거30일 안내를 그대로 적용하지 않는다. 계정의 실제 해제일과 최신 문서를 최종 기준으로 확인한다. Coming Soon 최소2주와 상점·제품 심사는 별도 조건이며 가능한 작업은 병행할 수 있다.

공개 가능 시점은 계정에 표시된 앱 결제 대기 해제일, Coming Soon 공개일+14일, 상점·제품 심사 승인 및 모든 미완료 항목을 충족한 뒤다. 검토 소요시간은 보장된 출시 날짜가 아니므로 아직 날짜를 확정하지 않는다. 현재 결제·새 AppID·공개 페이지가 없어 계산할 실제 시작 날짜도 없다.

- [ ] 출시자 최종 승인 후 Steamworks 공개 버튼을 실행하고 실제 고객 계정에서 구매/설치/실행과 상점 현지화를 확인한다.

공식 근거와 원문 확인 날짜는 [official-sources.md](official-sources.md)를 따른다.
