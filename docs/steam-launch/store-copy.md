2026-10-10 검토 초안. CODE:SHIFT는 가제이며 확정 이름으로 모두 교체한 뒤 제출한다. 아래 각 언어의 짧은 소개와 상세 소개만 상점 입력 후보이며, 개발 메모는 복사하지 않는다. 같은 본문은 `store-copy.json`에 필드별로 저장한다. 문구는 실제 출시 빌드와 대조하고 영어·일본어 원어민 감수를 거친다. 플레이 시간, 학습 성과, Steam Cloud·업적 활성화 또는 Steam Deck 지원을 약속하지 않는다.

## 한국어

### 짧은 소개

내 컴퓨터에서 시작하는 개발자 이야기. 작은 카페의 문제를 관찰하고, 코드를 고쳐 동네 의뢰를 해결하세요. 번 크레딧으로 작업실을 꾸미고, 배운 것을 연결해 내 첫 프로젝트 1.0을 배포하세요.

### 상세 소개

컴퓨터 한 대, 도착한 메시지 하나. 작은 카페가 당신의 도움이 필요합니다.

CODE:SHIFT는 가상의 바탕화면에서 의뢰를 맡고, 파일을 고치고, 결과를 확인하는 싱글 플레이 개발자 시뮬레이터입니다. 메시지, 브라우저, 편집기와 터미널을 직접 열어 작은 수리를 완성하고 동네 사람들의 다음 부탁을 만나세요.

**직접 바꿔 보는 첫 코드**

잘못된 간판과 잘린 메뉴판을 먼저 관찰하세요. 함께 배우기에서는 간판 이름을 직접 입력하고 너비 슬라이더를 조절합니다. 계산 연산자와 메뉴 주소도 직접 입력하고 주문 보관을 설정하세요. 변경을 파일에 저장하고 화면과 손님 주문에서 결과를 확인합니다. 힌트는 필요할 때 직접 열며 보상 불이익이 없습니다. 실패에 시간 제한이나 크레딧 손실도 없습니다.

**동네의 부탁을 맡으세요**

카페 3장 이후에는 세 단계로 이어지는 동네 의뢰 18개가 기다립니다. 가격표, 예약, 명단, 배송과 행사 보고서를 고치며 선택, 빈칸과 짧은 식으로 작업을 이어갑니다. 고객에게 보낸 답장은 마지막 편지에 반영됩니다. 선택 연습 의뢰 6개도 준비되어 있습니다.

**내 작업실과 내 첫 배포**

무료 기본 블루에서 시작해 번 크레딧으로 햇살 해변, 초록 정원, 오피스텔 작업실 배경을 구입하세요. 네 종류는 실제 바탕화면 이미지이며, 소유한 배경은 무료로 다시 적용할 수 있습니다. 복구 노트, 보조 모니터와 작업실 간판도 마련할 수 있습니다. 마지막에는 제목, 배치, 주소와 문의 보관을 연결한 동네 도움판을 만듭니다. 현재 파일을 검사하고 1.0.0을 기록한 뒤 첫 프로젝트를 배포하세요.

**직접 다루는 컴퓨터**

안내를 따라 시작하거나 직접 작업 모드에서 편집기와 가상 터미널을 사용할 수 있습니다. 게임 속 파일과 명령은 시뮬레이션 안에서 작동합니다. 한국어, 영어와 일본어로 플레이하고, 로컬 저장으로 진행을 이어가세요.

**더 고쳐 보고 싶다면**

선택 콘텐츠인 코드 실험실에서는 제한된 JavaScript 문법으로 12개의 함수 퍼즐을 직접 고칩니다. 조건과 반복, 배열과 집계에서 시작해 API 응답 규칙, 중복 요청, 원자적 처리와 캐시를 서로 다른 입력으로 시험하세요.

## English

### Short description

Start a developer's story on your own virtual desktop. Spot a cafe's problems, repair its code, and take on neighborhood jobs. Spend earned credits on your studio, then bring what you have learned together and ship your first 1.0 project.

### Long description

One computer. One new message. A small cafe needs your help.

CODE:SHIFT is a single-player developer simulator played through a virtual desktop. Open messages, a browser, an editor and a terminal yourself. Repair files, check what changed, and meet the people behind the next neighborhood request.

**Your first code changes**

Start by spotting a wrong sign and a menu that does not fit. In guided play, type the sign name and adjust a width slider. Type the calculation operator and menu address, then set order storage. Save changes to the files and check the result on screen and in customer orders. Open hints when you need them; they do not reduce rewards. Failed attempts have no time limit or credit penalty.

**Take on the neighborhood's requests**

After three cafe chapters, work through 18 neighborhood jobs across three stages. Fix prices, bookings, lists, deliveries and event reports using choices, blanks and short expressions. Your replies to customers shape the final letter. Six optional practice jobs are also available.

**Your studio. Your first release.**

Start with the free Default Blue wallpaper, then buy Sunlit Coast, Morning Garden or Studio Apartment with earned credits. These four choices change the actual desktop image, and owned wallpapers can be reapplied for free. You can also buy recovery notes, a second monitor and a studio sign. Bring titles, layout, routes and request storage together in your own neighborhood help board. Check the current files, record version 1.0.0, and publish your first project inside the game.

**A computer you can explore**

Follow the guided route or use Direct Work mode to work in the editor and virtual terminal. Files and commands run inside the game's simulation. Play in Korean, English or Japanese, and continue your progress with local saves.

**Keep experimenting**

The optional Code Lab offers 12 function puzzles using a limited subset of JavaScript. Test conditions, loops, arrays and reports, then explore API response rules, repeated requests, atomic updates and caching with different inputs.

## 日本語

### 短い紹介

自分の仮想デスクトップから始まる開発者の物語。小さなカフェの問題を見つけ、コードを直して、まちの依頼に応えましょう。稼いだクレジットで作業場を整え、学んだことをつなげて初めての1.0作品を公開します。

### 詳しい紹介

パソコン1台と、届いたメッセージ。小さなカフェがあなたの助けを待っています。

CODE:SHIFTは、仮想デスクトップで依頼を受け、ファイルを直し、結果を確かめるシングルプレイの開発者シミュレーターです。メッセージ、ブラウザー、エディター、ターミナルを自分で開き、小さな修正を完成させながら、まちの人々の次のお願いに出会いましょう。

**自分で変える、初めてのコード**

間違った看板と、画面に収まらないメニューを見つけるところから始めます。ガイド付きのプレイでは看板の名前を入力し、幅スライダーを動かします。計算の演算子とメニューのアドレスも入力し、注文の保存を設定しましょう。変更をファイルに保存して、画面とお客さんの注文で結果を確かめます。ヒントは必要なとき自分で開けます。使っても報酬は減りません。失敗に時間制限やクレジットのペナルティもありません。

**まちのお願いを引き受ける**

カフェの3章を終えると、3段階に分かれた18件の依頼が待っています。価格表、予約、名簿、配送、イベント報告を、選択肢や空欄、短い式で修正します。お客さんへの返事は最後の手紙に反映されます。任意の練習依頼も6件あります。

**自分の作業場と、初めての公開**

無料の標準ブルーから始めて、クレジットで陽だまりの海岸、朝の庭、ワンルームの作業場の壁紙を購入できます。4種類とも実際のデスクトップ画像が変わり、購入済みの壁紙は無料で再適用できます。復旧ノート、追加モニター、作業場の看板も購入できます。最後は見出し、レイアウト、アドレスと問い合わせ保存をつなげ、まちの案内板を作ります。現在のファイルを検査し、1.0.0を記録して、ゲーム内で初めての作品を公開しましょう。

**自分で操作するパソコン**

ガイドに沿って進めるほか、直接作業モードでエディターや仮想ターミナルを使えます。ファイルとコマンドはゲーム内のシミュレーションで動作します。韓国語、英語、日本語でプレイし、ローカル保存で続きを楽しめます。

**もっと試したいなら**

任意のコード実験室には、JavaScriptの限られた構文を使う12個の関数パズルがあります。条件、繰り返し、配列、集計から、API応答規則、重複要求、アトミックな更新、キャッシュへ。異なる入力で結果を確かめましょう。

## Code Lab 公開条件 — 編集メモ

0.11では12課題と制限付きインタープリターを実装しており、上の本文にその範囲を記載した。自動検証を人間の初心者テストや学習効果の証拠として扱わない。最終ビルドでメニュー到達、12課題の正解・不正解判定、保存と復元、3言語を確認してから公開する。Code Labを同梱しないビルドでは追加段落を削除する。自由なJavaScriptの全仕様、実ネットワークやホストのコード実行を約束しない。

- KO: 선택 콘텐츠인 코드 실험실에서는 12개의 짧은 함수 문제를 직접 고칩니다. 계산과 조건에서 시작해 배열, 집계와 요청 처리 규칙까지, 서로 다른 입력으로 결과를 시험하세요.
- EN: In the optional Code Lab, repair 12 short function challenges. Move from arithmetic and conditions to arrays, reports and request-handling rules, testing your results against different inputs.
- JA: 任意のコード実験室では、12個の短い関数課題を直接修正します。計算と条件から配列、集計、要求処理のルールへ進み、異なる入力で結果を確かめましょう。
