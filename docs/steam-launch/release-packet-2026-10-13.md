게임 속 터미널·파일·설치·CatHub는 시뮬레이션이다. 실제 Windows 시스템을 설치·수정하는 도구처럼 설명하지 않는다. 최종 제작은 준비된 프로젝트 파일과 검증 규칙 안에서 작성하고, 지원되는 웹 결과물을 내보내는 범위다. 임의의 웹앱, npm 생태계 전체, 모든 Python/SQL 문법, 실무 숙련을 보장하는 문구를 사용하지 않는다.
