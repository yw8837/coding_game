# CODE:SHIFT 0.11 RC — 관찰에서 함수 작성까지

2026-10-09. CODE:SHIFT는 가제이며 한국 Steam 판매 계획 가격은 21,000원이다.

기존 카페 3장 → 동네 의뢰 18개 → 내 프로그램 1.0.0 배포 → 마지막 편지의 흐름을 유지한다. 타이틀에서 시작하면 빈 바탕화면이 열리고, 메시지 앱부터 직접 조작한다. 함께 배우기에서는 선택 → 한 글자 입력 → 빈칸 → 짧은 코드 순서로 진행하며 언제든 직접 작업으로 전환할 수 있다.

## 작업실 바탕화면

하단 작업표시줄을 왼쪽 시작·검색, 중앙 앱, 오른쪽 시스템 트레이·시계·날짜·바탕화면 보기로 정리했다. 기기의 실제 날짜와 시간을 표시하며 390px에서도 시계를 유지한다. 시계를 누르면 월 이동과 오늘 복귀가 가능한 달력이 열리고, 최근 실행한 실제 터미널 명령을 확인할 수 있다. 날짜 없는 명령 기록에 임의로 날짜를 붙이지 않는다.

시작 메뉴에는 성공한 `code` 명령으로 연 최근 파일을 최대 세 개 표시한다. 없는 파일은 제외하고, 클릭하면 같은 가상 파일을 에디터에서 이어서 편집한다. 시작 메뉴와 달력은 서로 겹쳐 열리지 않으며 Escape로 닫으면 열었던 버튼으로 초점이 돌아간다. 기존의 바탕화면 그림과 빈 초기 바탕화면은 유지한다.

## 새 코드 의뢰

선택 연습 앱에 기존 규칙 실험 6개와 **코드로 해결하는 의뢰 12개**를 연결했다. 카페나 엔딩의 필수 조건을 늘리지 않았다. 경험자는 원하는 문제를 바로 선택할 수 있다.

| 단계 | 문제 | 다루는 개념 |
| --- | --- | --- |
| 한 줄의 변화 | 영수증, 할인, 재고, 배송비 | 입력·반환, 계산, 조건·경계, null·기본값 |
| 여러 손님의 주문 | 주문 합계, 품절 메뉴 | 반복문·누적, filter·map |
| 정리해서 전달하기 | 명단, 매출 장부, API 응답 | 문자열·중복 제거, 객체 집계, 경로·메서드 조건 |
| 서비스 지키기 | 재시도, 묶음 예약, 캐시 | 멱등성, 검증 후 적용, 만료 시간 경계 |

먼저 잘못된 결과를 관찰하고, 함수를 고쳐 여러 입력에서 검사한다. 정해진 답안 문자열을 맞추는 방식이 아니다. Acorn으로 구문을 읽고 지원 범위 안의 JavaScript를 게임의 해석기로 실행한다. 예를 들어 반복문 풀이와 reduce 풀이 모두 결과가 맞으면 통과한다. 구문·실행 횟수·자료 크기에 제한이 있으며 브라우저 API, 네트워크, 파일, 운영체제 접근은 없다.

힌트와 전체 예제는 선택해서 볼 수 있다. 예제를 적용해도 직접 검사를 실행해야 하며 보상 차감은 없다. 첫 완료 보상은 한 번 지급하고 이후 재검사는 연습으로 남는다. 성공 후에는 거의 맞는 코드의 버그를 드러내는 JSON 입력을 직접 만드는 **반례 도전**이 열린다. 반례 보상도 한 번만 지급한다.

초안·성공 기록·검사 증거·반례 입력·최소 해석기 연산 수를 저장한다. 코드를 바꾸거나 입력 묶음을 바꾸면 이전 검사 증거는 지운다. 과거 완료 기록은 유지한다. 해석기 연산 수는 실제 컴퓨터의 실행 속도나 성능 측정값이 아니다.

## 터미널에서 직접 작업하기

코드 의뢰에서 파일 작업을 준비하면 가상 PC의 `/home/dev/code-lab`에 함수 파일·입력 JSON·테스트 파일을 받는다. 터미널에서 직접 입력하고 실제 가상 파일을 편집한다.

```sh
sudo apt update
sudo apt install nodejs
cd /home/dev/code-lab
cat receipt.js
code receipt.js
node run.cjs receipt.js receipt.input.json
node --test receipt.test.cjs
```

`code`는 해당 파일을 에디터에서 연다. 저장하면 터미널과 코드 의뢰가 같은 소스를 읽는다. `run.cjs`는 입력 JSON으로 함수를 호출하고, `--test`는 의뢰의 테스트를 실행해 실패한 입력과 기대·실제 결과를 출력한다. 코드나 입력을 바꾸면 다시 실행해 차이를 확인할 수 있다. 검사 통과 보상은 GUI와 터미널에서 합쳐 한 번만 지급한다.

실행기는 여전히 게임 안의 제한된 JavaScript 해석기다. 호스트 Node·파일·운영체제를 실행하지 않는다. 배포한 CommonJS 실행·테스트 파일의 의미는 별도 작성자 제공 예제로 실제 Node에서도 비교한다. 사용자가 작성한 임의 코드는 실제 PC에서 실행하지 않는다.

## 출시와 실제 플레이 확인 자료

- 실제 0.10 플레이로 만든 42초 트레일러: KO/EN/JA 가로판과 KO 세로판. 새 학습 경로와 최종 프로젝트가 보이며, 0.11 코드 의뢰는 포함하지 않는다.
- 마케팅 자막 없는 1920×1080 게임 스크린샷 14장.
- 사용자가 먼저 플레이한 뒤 주변 초보자 3–5명과 확인할 수 있는 오프라인 관찰 도구. 익명 기록·도움 여부·막힌 지점·재미 평가, JSON/CSV 내보내기와 가져오기를 제공한다. 실제 참여자 결과는 아직 없다.
- 세 언어 Steam 상점 초안·등록 순서·콘텐츠 설문 초안·업적 목록. Steam 사전 점검 CLI는 실제 앱/디포 ID와 Steam 패키지를 확인하고 Preview=1 VDF만 생성한다.

## 빌드

React·TypeScript 게임을 Vite로 묶고 Electron 44 Windows x64 실행 폴더로 패키징한다. 사용자는 Node, npm, Godot, Unity를 설치할 필요가 없다. 실행 파일과 동봉 파일을 모두 유지해야 한다. 개발자가 소스를 수정하고 다시 빌드할 때만 Node와 의존성이 필요하다. 웹판과 Windows판은 같은 게임 로직을 쓴다.

Windows 오프라인 RC 전달은 Steam 출시와 다르다. 해당 게임은 Steam 미등록이며, 확인한 파트너 계정의 앱 크레딧은 0개였다. 기존 다른 게임의 AppID 5336990을 재사용하지 않는다. 등록비 결제, 앱 생성, 실제 Steam 동작과 심사는 아직 수행하지 않았다. 자동 기능 검사는 초보자의 재미·학습 성과를 검증한 인간 플레이 테스트가 아니다.
