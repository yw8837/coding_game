# 0.12 RC 검증 기록

2026-10-10. 버전 `0.12.0-rc.0`. C: 원본에서 검사했으며 브라우저와 네이티브 빌드·실행을 순서대로 진행했다. 실제 사용자 프로필을 테스트에 사용하지 않았다.

## 범위

카페 3장, 한·영·일 18개 의뢰 직접 입력·고객 상황 실행·엔딩, 직접 작업 설정, 수동 힌트, 잘못된 입력과 수정 후 재실행, 보상/저장 경계, 1440/390px, Windows 실제 UI·패키지, 코드·의존성 보안 검사를 대상으로 한다.

실제 사람의 재미·이해도·학습 성과, 별도 PC 최소 사양과 코드 서명, Steam 실제 등록·연동·심사는 자동화 QA 범위에 포함하지 않는다.

## 결과

- 게임 단위 검사 **210/210**, 데스크톱 단위 검사 **31/31** 통과. 합계 **241/241**, 실패·취소·스킵 0개. 신규 고객 상황, 실제 결과 계산, 저장 호환성, 강화된 전달 판정과 잘못된 입력 복구를 포함한다.
- TypeScript 통과. 전체 ESLint 248개 파일에서 오류 0개·경고 69개. 경고까지 모두 해소했다고 표현하지 않는다.
- 카페: 한·영·일 각각 새 프로필로 3장, 손님 3명, 실제 API 요청, OPEN과 첫 동네 의뢰 진입 통과. 빈 입력 차단, 틀린 값의 실제 파일 반영과 수정, 수동 힌트, 요청 수량의 고정 목표 금액, 실제 GET 메뉴 표시를 확인했다. 페이지 오류 0개.
- 후반: 한·영·일 각각 **18개 의뢰 → 내 웹앱 1.0.0 → 균형 엔딩** 통과. 수동 도움으로 예시를 입력한 뒤 별도 적용하는 자동화 경로이며, 사람이 도움 없이 배웠다는 증거가 아니다. 고객 상황을 실행해도 저장과 보상이 바뀌지 않고, 파일 수정 후 이전 결과를 숨기며, 모든 제공 상황의 수정 후 결과가 맞는지 확인했다. 선택기 Tab → 실행 버튼 Enter도 검사했다. 페이지 오류 0개.
- 세 언어·3개 장의 1440/390px 화면을 저장하고 모바일 퀘스트를 닫은 실제 편집 화면에서 가로 넘침이 없음을 확인했다. 밝은 고객 결과 카드의 설명 글자 대비를 보완했다.
- 첫 카페 테스트에서 기존 `.game-desktop`와 `.pc-shell`의 동일 우선순위로 인한 레이아웃 충돌을 발견했다. 현재 셸의 선택자 우선순위를 높이고, legacy 그리드 규칙을 뒤에 삽입해도 flex 배치와 하단 작업표시줄이 유지되는지 세 언어로 재검사했다. 재검사 전체 통과.
- 소스 교차검토에서 카페 파일을 외부 편집한 뒤에도 이전 저장 피드백이 남는 결함을 수정했다. 저장·GET·POST 결과의 소스 스냅샷이 현재 파일과 맞을 때만 표시한다. 해당 수정은 소스 재검토 승인; 외부 편집을 왕복하는 별도 브라우저 재현은 이번 전체 카페 시나리오에 포함하지 않았다.
- 기존 0.11 판정으로 이미 전달된 두 결함 저장과 정상 18개 의뢰·출시·엔딩 저장이 읽기→쓰기→재불러오기에 성공했다. 새 revision 외의 파일·완료·보상·응답·출시·엔딩 보존을 비교했다. 새 전달에는 구 저장에서도 강화된 검사를 적용한다.
- 웹 보안 UI: 잘못된/과대 JSON 거부 후 이전 저장 보존, 이력 문자열 이스케이프, 실제 미리보기의 script·외부 URL 제거와 CSP, 제한 실행기의 무한 루프·전역·constructor 거부 및 정상 풀이 복귀를 확인했다. 외부 프로브 요청·스크립트 실행·페이지 오류 0개. 무취약성 보장은 아니다.
- 웹 운영 의존성 감사 0건, Windows 운영 의존성 감사 0건. 전체 개발/빌드 범위는 **미패치 braces High 1건**이 남는다. [보안 검토](security/review-0.12.md)에 범위와 공식 근거를 기록했다.
- 소개 페이지 세 언어의 30초 영상 재생·탐색, canonical 메타데이터, 빈 바탕화면 시작과 터미널 help 통과. 영상은 0.11.1 촬영본을 유지했으며 새 렌더나 실제 청취 검증으로 표현하지 않는다.

## Windows

- 최종 소스로 렌더러 빌드 성공. JavaScript 약 1.26 MB이며 번들 크기 경고가 남는다.
- Electron 실제 UI에서 카페 3장·후반 18개·최종 출시·엔딩 통과. 직접 작업 모드가 후반 의뢰와 최종 프로젝트에서 전체 코드로 시작함을 확인했다. Code Lab, 터미널 파일 편집, 달력, 종료 저장·재실행, 백업 가져오기/내보내기, 손상된 주 저장의 백업 복원도 통과. 페이지 오류 0개.
- QA 패키지의 실제 실행 파일에서 일본어 설정 유지, 의뢰 수락 저장, 종료 후 복원, Node 비노출 통과.
- 배포용 Windows x64 오프라인 RC 생성·검사 통과. QA 플래그 false, Steam AppID null, Steam 모듈 미포함, 라이선스와 실행 제한 fuse를 확인했다. QA 패키지와 게임 파일 22개가 동일하고 이미지 8개의 내용이 소스와 일치한다. ASAR에는 파일 153개가 있다.
- 웹 공개 배포와 공유 ZIP의 최종 식별자·CRC·SHA-256은 전달 폴더의 영수증과 무결성 목록에 기록한다. 이전 RC와 사용자 저장은 보존한다.
