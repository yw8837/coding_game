# CODE:SHIFT 0.12 RC — 고친 결과를 직접 확인하기

2026-10-10. CODE:SHIFT는 작업명이다. 웹판과 Electron Windows x64 오프라인판은 같은 게임을 사용한다.

## 플레이 흐름

- 카페 3장 다음의 18개 의뢰도 첫 장부터 값을 직접 입력한다. 선택 예시는 수동 도움 안에서 입력 초안만 채우며, 적용·검사·전달을 대신하지 않는다. 실제로 저장된 변경 코드를 확인할 수 있다.
- 18개 고객 화면에서 영수증·대출·판매 목록·시간표·배달비·API 요청 등의 상황을 선택해 실행한다. 결과는 전달 검사와 같은 파일 해석기로 계산한다. 한 상황의 성공이 의뢰 전체 성공을 의미하지 않으며, 실험만으로 보상을 주지 않는다.
- 파일이나 상황이 바뀌면 오래된 결과를 숨기고 재실행을 안내한다. 편집 화면에 들어가면 고객 화면은 접혀 있고 필요할 때 다시 펼친다. 고객 화면은 마우스와 키보드로 조작할 수 있다.
- 직접 작업 설정은 후반 의뢰와 최종 프로젝트에서도 전체 코드 편집으로 이어진다. 전달 후 다음 고객을 지도에서 직접 고르거나 선택 코드 연습으로 이동할 수 있다.
- 초반 현재 목표와 입력 근처의 저장·수동 힌트를 정리한다. 손님이 주문한 수량의 목표 금액은 준비한 수량과 분리하며, 수정 뒤에 이미 해결한 고장 설명을 반복하지 않는다. API 응답은 실제 메뉴 데이터로 보여 준다.
- 마지막 프로젝트의 정답 문구를 상시 노출하지 않는다. 힌트와 예시는 플레이어가 직접 연다. 기존 카페→18개 의뢰→내 웹앱 1.0 출시→마지막 편지의 목표를 유지한다.

## 판정과 보안

빵집에서 다섯 개 묶음을 이용해 일부 계산만 맞추는 우회와, 예약 입력/버튼이 실제 폼 밖에 있는 HTML도 통과하던 결함을 수정했다. 제한된 HTML 지원 범위를 명시한다. 기존 버전에서 이미 전달된 의뢰는 당시 판정을 인정하여 파일·보상·완료·엔딩을 보존한다. 새로 검사하고 전달하는 의뢰는 구 저장을 이어서 플레이할 때도 강화된 판정을 적용한다. 실제 구버전 저장의 읽기·쓰기·재불러오기와 중복 보상 방지를 검사했다.

바탕화면과 예전 화면 배치의 CSS 우선순위 충돌을 수정했다. 스타일 적용 순서가 달라져도 바탕화면과 작업표시줄이 상단 그리드로 찌그러지지 않는지 브라우저에서 검사한다.

운영 의존성 감사와 실제 입력 경계 검사는 별도 QA에 기록한다. 개발/빌드용 braces 경고에는 아직 공식 패치 버전이 없으며, 경고가 사라졌다고 주장하지 않는다.

## 가격

정가 11,000원에 대한 출시 할인율은 사용자 최종 선택 대기다. 현재 추천은 첫 7일 20%(8,800원)이며 이전 안은 10%(9,900원)이다. Steam 출시 할인 최대치는 40%(6,600원)이므로 50%는 설정할 수 없다. 실제 할인은 예약하지 않았다.

**한국 정가 11,000원(추천), 출시 첫 7일 20% 할인 8,800원.** 현재 콘텐츠와 공식 Steam 비교작 7개를 기준으로 한 권장안이다. 가격을 실제 상점에 적용하지 않았다. 조사와 할인 조건, 무료 웹판과 유료판의 가치 차이는 [가격 근거](pricing-2026-10.md)를 참고한다.

기존 30초 홍보영상은 이전 0.11.1 게임에서 촬영한 실제 카페 수리·구매·첫 출시 장면이다. 이번에 추가한 후반 고객 실험 화면을 새로 촬영한 영상은 아니다. 촬영본과 음악 크레딧은 그대로 제공한다.

사용자 계획에 따라 Steam 본편을 실제 구매할 수 있게 된 뒤 웹판을 홍보 데모로 전환한다. 카페 입문 3장·OPEN 범위를 권장하며, 기존 전체판 저장의 보존·백업 내보내기와 본편 가져오기를 유지한다. 이번 0.12 웹 배포에서는 콘텐츠 제한을 적용하지 않았다.

## 출시 상태

자동 검사는 기능과 판정의 검증이며 재미·교육 효과·플레이타임의 실측이 아니다. 실제 초보자 참여, 별도 Windows 장비, 서명, 이 게임의 Steam 등록·심사는 남아 있다. 다른 게임 AppID 5336990을 사용하지 않는다. 정확한 검사 결과는 [QA 기록](QA-0.12-RC.md), 배포·ZIP 식별자는 전달 폴더의 영수증을 참고한다.
