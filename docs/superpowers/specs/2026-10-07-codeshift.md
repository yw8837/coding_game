# CODE:SHIFT — playable prologue

Build a Korean browser-playable developer simulator, working title CODE:SHIFT. The user approved an integrated virtual desktop/internet with Grome → COOCLE → CatHub → terminal → editor → review → deployment and clear achievement. Every shell, package, repository, and server operation is simulated in game memory; never execute player terminal commands on the host.

## First release

Three linked commissions for Mono Cafe: repair responsive CSS, repair a JavaScript order total, and make a Python order API persist records and run on a virtual Ubuntu server. One project grows through all three. The full beginner-to-upper-intermediate campaign and an actual embedded local LLM remain future work; do not label authored NPC hints as a running model.

The desktop opens directly on the working surface, with a task brief, terminal and browser. Dark ink surfaces, sharp window chrome, mint terminal accent, warm orange mission accent; readable Korean. App switching and layouts work on narrow screens. Autosave is explicitly device-local, can be exported/imported, and resets only after confirmation.

## Simulation rules

- Track machines, working directories, files, installed programs, project dependencies, running processes and ports separately.
- Parse supported shell arguments and paths. Unknown commands clearly identify the simulator's supported scope. Familiar supported failures distinguish missing npm, missing package.json, missing scripts/dependencies and occupied ports.
- Git staging, local commits, remote branch heads, approved PR, merged main and deployed snapshots are separate. Later working edits do not change an earlier commit or release.
- HTML/CSS preview and responsive checks use sandboxed browser rendering, with no network and no same-origin privilege. JavaScript arithmetic uses a bounded parser, never eval. Python lesson uses explicitly documented supported configuration/route semantics, not arbitrary CPython.
- A virtual API and database share order state. Python processes load a source snapshot; edits need restart. Virtual local and remote server environments remain separate.
- Grade deterministic outcomes and the actual submitted snapshot, never the presence of a magic command or an LLM answer. A reward is paid once per commission.
- Fictional external-looking URLs stay inside the game. No real Google/GitHub/account connection, package installation or player-code shell execution.
