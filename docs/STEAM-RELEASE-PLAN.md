# Steam 정식판 방향 — 2026-10-09

CODE:SHIFT는 작업명이다. 최종 판매 플랫폼은 Steam PC판이며 한국 기준 가격안은 **₩9,900**이다. 출시 첫 7일 10% 할인(8,910원)을 권장한다. 다른 통화 가격과 출시일은 미정이며 가격 적용·상점 등록·출시를 완료하지 않았다. 현재 브라우저 빌드와 Windows 오프라인 RC는 제품 구현 및 검증 자료다.

## 실제 상태와 남은 출시 조건

메인 담당이 2026-10-09 실제 로그인한 Steamworks 화면에서 이 게임의 앱 미등록과 사용 가능한 앱 등록 크레딧0을 확인했다. 접근성 snapshot에서 읽었고 파일로 저장된 별도 화면 증거는 없다. 기존 AppID **5336990은 다른 게임 Veins of Sleeping Moon**이므로 이 프로젝트에 사용하지 않는다. 이 게임의 새 AppID, Windows depot ID와 패키지 연결은 아직 필요하다. SDK 예제480이나 추측한 ID도 사용하지 않는다.

현재 카페3장, 동네 의뢰18개, 선택 연습6개, 작업실 구매, 최종 프로젝트 검사·1.0.0 배포, 고객 답장에 따른 엔딩이 구현되어 있다. Windows x64 오프라인 패키지, 로컬 저장/백업 및 복구, 한국어·영어·일본어와 자동 언어 선택이 있다. 데스크톱 런타임은 Electron이며 Steam 연동 경계와 9개 업적 allowlist가 구현되어 있다. 이것을 실제 Steam 실행·업적 획득·Cloud나 설치 승인 완료와 혼동하지 않는다.

메인 작업의0.11 보고에 따르면 선택 Code Lab12개와 제한된 JavaScript 인터프리터는 구현되었고180개 테스트·타입 검사를 통과했다. 브라우저·최종 패키지 검증은 진행 중이다. 함수 퍼즐로 조건·반복·배열·집계·API 응답 규칙·멱등성·원자적 처리·캐시를 다룬다. 일반 JavaScript 전체 실행, 실제 네트워크 API 서비스나 중상급 실무 숙달을 보장하지 않는다. 출시 빌드에 포함하고 검증된 경우에만 상점 문구를 유지한다.

코딩 비경험자 인간 플레이테스트와 영어·일본어 원어민 감수는 미완료다. 자동 완주는 이해도·재미·학습 성과·실제 플레이 시간의 증거가 아니다. “본편6~8시간”, “초보자 검증 완료”와 같은 약속을 상점에 넣지 않는다. 15세 전후는 설계 타깃이며 공식 연령 등급이 아니다.

## 정식판의 경험과 가격

한 대의 가상 컴퓨터에서 메시지를 열고, 문제를 관찰하고, 선택과 작은 수정으로 파일을 바꾸며, 결과를 검사한다. 카페 입문→동네 의뢰→자신의 첫 프로젝트 배포로 성장한다. 안내를 사용하는 함께 배우기와 직접 편집기·가상 터미널을 사용하는 직접 작업을 제공한다. 실패에 시간 제한·크레딧 손실이 없고 힌트에 보상 불이익이 없다. 크레딧은 가상 작업실 구매에 사용하며 현금 결제나 환전 기능은 없다.

₩9,900은 한국 정식판 가격안이며 Steam에 등록한 가격이 아니다. 지역별 가격은 단순 환율 고정 대신 Steam 지역 도구와 시장을 검토한다. 현 분량이 가격을 뒷받침하는지는 인간 플레이테스트로 판단한다. 반복·대기·타이핑으로 시간을 늘리거나 검증되지 않은 추가 분량을 약속하지 않는다. 이 가격 방향은 현재 브라우저 접근을 닫거나 자동 유료화하는 실행 지시가 아니다.

## 언어 정책 — 구현된 상태

설치 국가나 다운로드 서버로 언어를 강제하지 않는다. 한국어·영어·일본어는 모든 판매 지역에서 선택할 수 있다.

1. 저장된 명시적 선택ko/en/ja가 최우선이다.
2. 자동이면 사용 가능한 Steam 게임 언어를 사용한다. koreana→ko, english→en, japanese→ja로 매핑한다.
3. Steam 정보가 없거나 미지원이면 OS 선호 언어 목록, 브라우저판에서는 navigator.languages를 확인한다.
4. 지원 언어가 없으면 영어로 시작한다.

`lib/game/locale.ts`와`i18n.tsx`는 저장된 선호auto/ko/en/ja와 현재 표시 언어를 분리한다. 수동 선택과 느린 플랫폼 응답이 충돌해도 수동 선택을 보존한다. 설정의 자동/수동 선택은 구현되어 있으며 예전 문서의 “기본ko만 지원, 자동 메뉴 없음”은 현재 상태가 아니다. 언어 변경은 게임 진행·코드·입력을 초기화하지 않는다. 실제 Steam에서의 언어 변경은 실제 새 AppID 런타임으로 추가 확인한다.

## 플랫폼·요구사양·Steam 기능

Windows x64를 현재 출하 검토 대상으로 둔다. 게임 속 가상 운영체제와 실제 지원 OS를 구분한다. 별도 저사양 PC에서 실측한 최소 OS/CPU/RAM/GPU/설치 용량은 아직 미확정이다. 개발 PC와 Electron 기술 하한을 최소 사양으로 대신 기입하지 않는다. Linux, macOS, Steam Deck와 컨트롤러 지원은 별도 패키지 및 입력 검증 후 결정한다.

9개 업적의 구현 API 이름과 번역 초안은[카탈로그](steam-launch/achievements.json)에 있다. 실제 Steamworks 등록·실계정 해제는 미완료다. Cloud는 수동 설정 예시만 있으며 동기화·충돌·재설치·계정 전환 검증 전까지 상점에서 제공 기능으로 표시하지 않는다. 실제 Steam SDK 초기화, 라이선스, 업로드와 별도 PC 검증은[체크리스트](steam-launch/upload-checklist.md)를 따른다.
