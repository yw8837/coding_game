# Steam 정식판 방향 — 2026-10-09

## 사용자가 확정한 조건

- 최종 판매 플랫폼은 Steam이다. 현재 0.10 RC 브라우저판은 검증용 플레이 빌드이며 정식 유료판과 구분한다.
- 한국 판매 기준가는 **21,000원(KRW)**으로 기록한다. 다른 통화 가격, 출시 할인, 출시일은 미정이다. Steamworks 가격을 실제 등록한 기록은 아니다.
- 코딩을 모르는 15세 전후 플레이어가 바탕화면, 작업표시줄, 앱과 파일을 직접 조작하는 개발자 시뮬레이터다.
- 한국어·영어·일본어를 지원하고 첫 실행 기본 언어를 자동 선택할 수 있어야 한다.
- 제목은 계속 검토한다. CODE:SHIFT는 작업명이며 아래 후보를 제품에 적용하거나 확정하지 않는다.

현재 0.10 RC는 카페 3장·동네 의뢰 18개·내 첫 프로젝트 1.0.0 배포와 엔딩을 구현했다. 기본 언어 선택과 수동 변경은 locale 모듈 및 Windows 어댑터에서 동작한다. 실제 Steam 배포 상태와는 구분한다.

이 문서는 정식판의 제품 방향이다. `spec.md`, `RELEASE-0.7.md`, `QA-0.7.md`는 이미 만들어진 브라우저판의 구현·검증 기록으로 유지한다. 아래 기획 목표를 구현 완료나 확정 출시 약속으로 읽지 않는다.

## 제목 후보

이름의 약속: 컴퓨터 한 대에서 의뢰를 해결하며 개발자로 성장하는 게임. 코딩·일·생활을 알아볼 수 있는 일상 단어를 사용하고, 전문 명령어 지식이 있어야 이해되는 제목은 피한다. 직관성을 우선하되 지나치게 일반적인 이름의 검색·상표 식별력 한계를 함께 본다.

| 후보 | 영문 후보 | 일본어 표시 초안 | 전달하는 경험 / 주의점 |
|---|---|---|---|
| 프리랜서 코더 | Freelance Coder | フリーランス・コーダー | 고객 의뢰와 수입·평판 성장. 직업 설명에 가까워 고유성은 약함 |
| 코딩 데이즈 | Coding Days | コーディング・デイズ | 코딩하는 일상과 성장. 세 언어에서 읽기 쉬운 편이나 시뮬레이터 부제 필요 |
| 코더의 책상 | Coder's Desk | コーダーの机 | 바탕화면과 작업실 중심. 코드 편집 도구로 오인할 가능성 확인 필요 |

먼저 비교할 두 방향은 프리랜서 코더(직관성)와 코딩 데이즈(접근성)다. 일본어는 초안이며 원어민 감수 전이다. 실제 직업을 언급하는 후보에는 초보자도 시작할 수 있다는 소개 문구를 붙인다. 해킹이 주된 플레이가 아니므로 해킹을 약속하는 이름은 사용하지 않는다.

초기 웹 검색에서 Coding Life는 기존 공개 게임 프로젝트가 확인됐고, Code Desk는 실제 소프트웨어 업체명이 확인되어 우선 후보에서 제외했다. 다른 후보의 검색 결과가 적다는 사실은 사용 가능 증거가 아니다. 최종 후보에 대해 한국/미국/일본 상표, Steam 유사 제목, 도메인·계정, 원어민 발음/연상을 확인한다. 회사명으로도 사용한다면 법인명 중복을 별도로 확인한다. 이번 작업은 상표 등록 가능성이나 이름의 독점 사용을 확인한 것이 아니다.

## 기본 언어 정책 — 구현 및 현재 범위

설치 국가나 다운로드 서버의 지역으로 언어를 강제하지 않는다. 지역은 가격·세금 등 별도 문제이며 한국어/영어/일본어는 모든 판매 지역에서 선택할 수 있게 한다.

1. 게임에서 직접 고른 언어가 있으면 유지한다.
2. 선택이 `자동`이면 Steam `ISteamApps::GetCurrentGameLanguage()`를 사용한다. 이 API는 게임별 언어를 따르고, 별도 선택이 없으면 Steam UI 언어를 따른다.
3. Steam 정보를 얻지 못하거나 반환 언어를 지원하지 않으면 운영체제의 선호 언어 목록에서 첫 지원 언어를 고른다. 브라우저판은 `navigator.languages`를 같은 목적으로 사용한다.
4. 지원 언어가 없으면 영어를 사용한다.

Steam 코드는 `koreana → ko`, `english → en`, `japanese → ja`로 매핑한다. OS/브라우저의 `ko-KR`, `en-US`, `ja-JP` 등은 기본 언어로 정규화한다. IP 위치조회나 추적용 외부 서비스는 필요 없다. 오프라인에서도 동작한다.

사용자 선택값(`auto | ko | en | ja`)과 이번 실행에서 표시할 언어를 분리해 저장한다. 자동 감지한 값을 수동 선택처럼 저장하면 다음 실행의 Steam 언어 변경을 무시하게 되므로 그렇게 구현하지 않는다. 기존 `codeshift-language`의 유효한 저장값은 사용자의 선택으로 보존한다. 현재 `lib/game/i18n.tsx`는 기본값 `ko`와 저장값 복원만 지원한다. 자동 감지, Steam 연결과 `자동` 메뉴는 아직 없다.

타이틀에서 `한국어 / English / 日本語`를 언제든 찾을 수 있게 하고, 설정에 `자동(현재: 한국어)`처럼 표시한다. 언어 변경으로 진행, 파일, 창 입력을 초기화하지 않는다. 명령어·코드는 유지하고 설명·의뢰·오류 안내를 번역한다. 게임 이름은 확정 후 Steam의 언어별 앱 이름에도 동일한 체계로 적용한다.

수용 사례: 일본 OS+한국어 Steam→한국어, 한국 OS+일본어 수동 선택→일본어, Steam 불가+일본어 OS→일본어, 미지원 언어만 존재→영어, 자동 설정으로 Steam 언어 변경 후 재실행→새 언어, 손상 설정→안전한 자동 선택. 감지 API 실패와 오프라인도 포함한다.

## 21,000원 정식판의 제안 범위

현재 카페 세 의뢰는 조작과 구현을 확인할 수 있는 분량이다. 정식판은 다른 사람의 의뢰를 맡고 내 작업실을 키우는 전체 경험으로 확장한다. 아래 수치와 기능은 설계 목표이며 완료된 콘텐츠나 검증된 플레이 시간이 아니다.

- 입문→독립 작업→큰 프로젝트의 세 단계 성장. 같은 문자열 치환만 반복하지 않고 관찰, 비교, 진단, 수리, 검증에 다른 선택을 넣는다.
- 서로 다른 고객과 프로젝트의 주요 의뢰 18~24개를 초기 기획 목표로 잡는다. 실제 플레이테스트를 통해 재미없는 반복을 줄이고 규모를 조정한다.
- 크레딧으로 작업실·도구를 개선하고 평판으로 다음 의뢰가 열린다. 힌트를 써도 불이익이 없고, 선택 과제를 통해 더 능숙하게 해결할 여지를 남긴다.
- 의뢰 수락·해결 방식과 고객 관계가 후속 사건에 반영되고, 전체 캠페인의 성취를 정리하는 엔딩을 갖춘다.
- 본편 6~8시간을 초기 검증 목표로 삼되, 대기·반복·타이핑으로 시간을 늘리지 않는다. 스토어에는 실측 전 플레이 시간을 약속하지 않는다.
- Windows PC를 우선 패키징 대상으로 검토한다. 실제 운영체제 지원과 게임 속 Windows풍/Linux 환경은 구분한다. Linux/Steam Deck 지원 표시는 실제 패키지 검증 후 결정한다.
- 독립 실행/오프라인, 파일 기반 저장 및 복구, 버전별 세이브 이전, Steam 언어·도전과제·Cloud 저장, 설치/업데이트/종료 동작을 정식판 검증 항목으로 둔다. 데스크톱 런타임 선택과 Steam App ID는 아직 확정하지 않는다.

지역별 가격은 21,000원을 단순 환율 변환해 고정하지 않고 Steam 지역 가격 도구와 동종 시장을 검토해 별도 제안한다. 언어 설정은 결제 통화나 판매 지역을 변경하지 않는다. 정식판 가격 확정은 공개 브라우저 빌드를 자동 유료화하거나 기존 플레이어의 접근을 닫는 지시가 아니다.

## 다음 구현 순서

1. 언어 선택과 자동 감지 모델을 분리하고 브라우저에서 회귀 검사한다.
2. 카페 이후의 고객·성장·선택을 포함한 의뢰 한 묶음을 제작해, 비경험자 테스트로 이해도와 재미를 확인한다.
3. 데스크톱 런타임 비교와 Windows 설치판 검증을 진행하고 Steam 연동 경계를 만든다.
4. 제목 후보를 좁혀 이름 확인과 시각 디자인을 진행한다. 확정 전 타이틀·영상·저장소를 임의로 개명하지 않는다.
5. 실제 분량과 현지화를 검증한 뒤 Steam 상점 문구, 지역별 가격과 출시 일정을 확정한다.
