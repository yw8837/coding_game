# Steam 정식판 준비 — 0.13.1 RC

2026-10-10. **CODE:SHIFT는 작업명**, 최종 판매 플랫폼은 Steam PC판이다. 사용자가 정한 한국 정가는 **₩11,000**이며 **출시 할인율과 출시일은 미정**이다. 가격 적용·앱 등록·Steam 업로드·심사·출시를 완료하지 않았다. 현재 웹판은 전체 무료이며 Windows 오프라인 RC는 구현 및 검증 대상이다.

## 현재 구현 범위

가상 컴퓨터에서 메시지를 읽고 문제를 관찰해 파일을 수정·검사·전달하는 싱글 플레이 게임이다. 카페 입문 3장 이후 동네 의뢰 18개가 세 구역에 6개씩 열린다. 새 플레이에서는 **각 구역에서 원하는 4개씩 총 12개를 전달**하면 최종 프로젝트로 진행하며 나머지는 선택해 이어 할 수 있다. 기존 구역 업적은 해당 구역 6개 전체 완료를 요구한다. 기존 저장의 진행과 이미 배포한 프로젝트 스냅샷은 호환 경로를 유지한다.

빵 가격 계산·도서 대출·연락처 정리·배송 요금·행사 보고서의 **다섯 의뢰**는 설정 파일 대신 제한된 JavaScript 함수로도 풀 수 있다. 직접 작성·저장한 함수와 입력별 기대/실제 결과를 비교한다. 별도로 선택 연습 6개와 Code Lab 함수 퍼즐 12개가 있다. 제한된 코딩 퍼즐을 일반 JavaScript 실행, 실제 API 서비스 또는 중상급 실무 숙달로 소개하지 않는다.

최종 프로젝트는 장소 안내·행사 목록·포트폴리오 중 하나를 고르고 제목·설명·항목·분류를 직접 작성한다. 색과 목록·카드 배치, 검색·분류 필터, 화면 너비·연결 주소·문의 보관을 확인해 게임 안에서 1.0.0을 기록·배포한다. 고객 답장은 마지막 편지에 반영된다. 이를 실제 인터넷 서비스 배포나 Steam 출시로 혼동하지 않는다.

함께 배우기와 직접 작업 모드, 가상 작업실 구매, 한국어·영어·일본어 및 자동 언어 선택, Windows x64 오프라인 실행 경로, 로컬 저장·백업·복구가 구현되어 있다. 실패에 시간 제한·크레딧 손실이 없고 힌트에 보상 불이익이 없다. 크레딧은 게임 안 구매에 사용하며 현금 결제·환전 기능이 없다.

현재 빌드 결과는 [0.13.1 QA](QA-0.13.1-RC.md), [릴리스 기록](RELEASE-0.13.1-RC.md), [보안 검토](security/review-0.13.1.md)를 대조한다. 정적 검사·자동 UI 완주와 인간 검증을 구분한다. 사람의 코딩 이해·재미·실제 플레이 시간·높은 수준의 학습 효과, 영어·일본어 원어민 감수와 별도 저사양 PC 사양 측정은 미완료다. “초보자 검증 완료”, “6~8시간”, 학습/직업 숙련 보장을 상점에 넣지 않는다. 15세 전후는 설계 타깃이며 공식 등급이 아니다.

## 계정·가격·출시 조건

메인 담당이 2026-10-09 로그인한 Steamworks 화면에서 이 게임 미등록·사용 가능한 앱 등록 크레딧 0개를 확인했다. 문서 작성자가 계정을 독립 재확인한 결과는 아니다. 새 게임용 AppID·Windows depot·패키지 연결이 필요하다. **5336990은 다른 게임 Veins of Sleeping Moon의 ID이므로 사용하지 않는다.** 예제 480이나 추측한 ID도 사용하지 않는다. 이 준비 작업에서는 결제·새 AppID 발급·업로드를 실행하지 않는다.

한국 정가 ₩11,000은 Steam에 등록된 가격이 아니다. 지역별 가격은 Steam 도구와 시장을 검토해 결정한다. 첫 7일 20%·₩8,800은 추천안이며 할인 결정·예약이 아니다. [가격 조사](pricing-2026-10.md)의 비교 근거와 [공식 정책](steam-launch/official-sources.md)의 확인 날짜를 참고하고 실제 적용 전에 최신 조건을 다시 확인한다. 가격이 분량과 경험을 뒷받침하는지는 인간 플레이테스트로 판단하며 반복·대기·타이핑으로 시간을 늘리지 않는다.

Steam Direct 비용, 결제 후 대기, Coming Soon 공개 기간과 상점·제품 심사는 각각 별도 조건이다. 2026-10-09 기록된 공식 Onboarding 원문은 첫 몇 타이틀의 결제 후 대기를 21일, Coming Soon은 최소 2주로 안내한다. 심사는 통상 3~5영업일이며 최소 7영업일 여유를 권고한다. 실제 계정의 해제일과 최신 문서를 최종 기준으로 확인한다. 결제·앱 등록·공개 페이지가 없어 확정 출시 날짜를 계산할 실제 시작점도 없다.

## 웹 데모 전환 시점

사용자는 **Steam 본편을 실제 구매할 수 있게 된 뒤** 공개 웹판을 홍보 데모로 전환하기로 했다. 0.13.1 준비 및 배포만으로 웹 콘텐츠를 제한하지 않는다. 권장 데모 범위는 카페 입문 3장·OPEN이다. 전체 동네 의뢰, 선택 연습·Code Lab과 개인 프로젝트는 본편 범위로 안내한다.

전환 전에 기존 전체판 저장 보존·내보내기·본편 가져오기와 검증된 실제 상점 링크를 확인한다. 기존 저장을 지우거나 잘라 저장하지 않는다. 데모 제한·완료 화면·Steam 상점 연결은 미구현 후속 작업이다. 등록·심사만으로 현재 웹 접근을 줄이지 않는다.

## 언어·플랫폼·Steam 기능

모든 판매 지역에서 한국어·영어·일본어를 선택할 수 있다. 저장된 수동 선택이 우선이고 자동이면 Steam 게임 언어, OS 선호 언어(웹은 navigator.languages), 영어 fallback 순서로 처리한다. 언어 변경은 게임 진행·코드·입력을 초기화하지 않는다. 실제 Steam 언어 변경은 새 AppID의 런타임에서 추가 확인한다.

Windows x64가 현재 출하 검토 대상이다. 최소 OS·CPU·RAM·GPU·설치 공간은 별도 PC 실측 전까지 미확정이다. 개발 PC나 Electron 기술 하한을 제품 최소 사양으로 기입하지 않는다. Linux·macOS·Steam Deck·컨트롤러 지원은 검증되지 않았다.

9개 업적 API 이름과 번역 초안은 [카탈로그](steam-launch/achievements.json)에 있다. 실제 Steamworks 등록·실계정 해제는 미완료다. Cloud 설정 예시는 동기화·충돌·재설치·계정 전환 검증의 증거가 아니며 상점 제공 기능으로 표시하지 않는다. 실제 SDK 초기화·라이선스·설치·업로드 검증은 [체크리스트](steam-launch/upload-checklist.md)를 따른다.

## 상점·영상·다음 제출 준비

상점 소개 3언어, 콘텐츠 설문, 업적 번역과 캡슐 계획은 [steam-launch](steam-launch/README.md)에 있다. 사전 생성 AI 아트·문구·번역을 공개하는 설문 초안이며 live AI는 없다. 최종 권리 확인은 출시자에게 남는다. 캡슐은 크기·배치 계획 상태로 실제 파일은 미생성이다. CODE:SHIFT를 최종 이름으로 확정하거나 다른 후보를 적용하지 않았다.

`output/trailer-rebuild/final/`의 30초 KO/EN/JA 가로 영상과 KO 세로 영상은 **0.11.1 한국어 실제 UI 촬영본**이다. 현재의 선택 12/18 진행, 다섯 JavaScript 대안 풀이, 개인 프로젝트와 Code Lab을 보여 주지 않는다. 현재 빌드 대표 스크린샷·영상은 최종 출하 범위에 맞춰 새로 촬영·선택하고 사람이 전체 시청·청음해야 한다. 음악 **Realizer**의 Kevin MacLeod 출처, CC BY 4.0 및 `ATTRIBUTION.txt`를 보존한다. 기존 42초 0.10 영상은 보관 자료다.

다음 단계는 현재 RC의 gameplay/저장/production/native 결과 대조와 사람의 제품 검증, 최종 이름·권리·저사양 실측, 소유자의 새 게임 식별자 준비, 최종 상점·설문·캡슐·가격 작성, 실제 Steam 빌드와 업적 검증, Coming Soon·심사, 소유자의 최종 공개다. 준비·승인·업로드를 출시 완료로 기록하지 않는다.
