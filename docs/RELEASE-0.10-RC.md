# CODE:SHIFT 0.10 RC — 작은 수리에서 내 첫 배포까지

2026-10-09. 작업명 CODE:SHIFT. 브라우저와 Windows x64 오프라인판이 같은 파일·진행·검사 규칙을 사용한다.

## 플레이와 성장

시작 버튼을 누르면 앱이 열리지 않은 바탕화면에서 시작한다. 메시지를 직접 열어 의뢰를 수락한다. 기본 **함께 배우기**는 다음 순서로 진행한다.

1. 카페 1장: 잘못된 간판과 잘린 메뉴판을 보고 선택한다. 선택은 실제 HTML/CSS 파일을 바꾸고 화면에 반영된다. 바꾼 코드 한 줄과 이유를 읽은 뒤 다음으로 간다.
2. 카페 2장: 계산 기호 한 글자를 입력한다. 고친 계산대로 서로 다른 세 손님의 주문을 직접 맞춘다.
3. 카페 3장: 주소와 보관 값을 한 칸씩 입력한다. 준비는 버튼으로 묶고, 실제 가상 API 요청으로 메뉴와 주문 보관을 확인한다. 준비·전송 명령은 펼쳐 보는 기록에 남는다.
4. 동네 의뢰 18개: 37개의 개별 값 수정으로 구성한다. 첫 장은 선택, 다음 장은 빈칸, 마지막 장은 실제 JSON 속성 문법과 명시적으로 설명한 짧은 조건·계산 식을 사용한다. 힌트는 값을 입력 칸에 채우고 적용은 플레이어가 한다.
5. 최종 프로젝트: 제목·너비·장소 주소·문의 보관을 고쳐 **나만의 동네 도움판 1.0.0**을 배포한다. 미리보기에서 장소를 불러오고 문의를 보내 동작을 확인한다.

실패에 시간 제한·크레딧 손실은 없다. 도움을 써도 보상이 줄지 않는다. 전체 코드 편집과 직접 터미널 작업도 유지한다. 설정에서 **직접 작업**으로 카페의 원래 앱별 흐름을 사용할 수 있다. 도움 모드의 계산 기호 수정은 사용자 파일 전체를 덮지 않고 해당 토큰만 바꾼다.

## 목표와 엔딩

타이틀과 퀘스트에 **카페 오픈 → 동네 의뢰 18개 → 내 첫 정식 배포**라는 목표가 표시된다. 카페 오픈은 입문 완료이며 전체 엔딩으로 표시하지 않는다.

최종 프로젝트는 현재 파일 검사 → 1.0.0 기록 → 배포를 순서대로 수행한다. 파일을 바꾸면 이전 검사와 버전 기록은 무효가 된다. 배포 후 파일은 읽기 전용이며 중복 보상은 없다. 마지막 편지는 고객에게 보낸 답장에 따라 세 가지 결말 중 하나로 이어지고, 완료 후 지도·바탕화면·배포한 프로그램으로 돌아갈 수 있다.

이전 버전에서 이미 받은 엔딩은 보존한다. 최종 프로젝트를 완료한 것처럼 소급 기록하지 않고, 추가 프로젝트를 진행할 수 있다.

## 컴퓨터 조작과 크레딧

- 브라우저는 전 언어에서 **Ghrom**으로 표기한다. 바탕화면·작업 표시줄·시작 메뉴·창 제목에 같은 자체 SVG 아이콘을 쓴다. 메시지의 “게임 캐릭터와 나누는 메시지” 문구를 제거했다.
- `clear`와 Ctrl+L은 화면만 지우고 명령 기록을 유지한다. ↑↓ 기록, Ctrl+C 입력 취소, Tab 명령·옵션·따옴표 경로·출력 대상 완성을 지원한다.
- `cd -`, `ls -a/-l/-h/-1` 조합, 여러 파일 `cat`, `echo -n`, `echo/cat > file`·`>> file`을 지원한다. `/pwd`에는 `pwd`와 절대경로의 차이를 안내한다.
- 셸 연결·파이프·백그라운드·명령 치환은 지원하지 않으며 전체 명령을 실행 전에 거부한다. 호스트 실행은 없고 가상 파일과 기존 검사·읽기 전용 경계를 유지한다. `cd -`의 이전 위치는 최근 100개 기록 범위다.
- 상단 잔액을 누르면 상점이 열린다. 테마는 90 cr, 복구 노트 250 cr, 보조 모니터 600 cr, 작업실 간판 900 cr이다. 구매는 실제 잔액을 차감하고 저장된다. 도구는 카페 오픈 후 열리며 엔딩 필수 조건이 아니다.

## 전달 범위

검증과 제한은 [QA-0.10-RC.md](QA-0.10-RC.md), 학습 흐름과 목표는 [ENDING-AND-LEARNING.md](ENDING-AND-LEARNING.md)에 기록한다. Git SHA, 공개 버전, 패키지 해시는 출시 자료의 `delivery-receipt.json`과 `integrity-manifest.json`이 식별한다.

소개 페이지는 새 내용을 반영했다. 기존 42초 영상은 **0.9 실제 플레이 자료**로 명시하고 이번 업데이트 영상처럼 표시하지 않는다. 이번에는 새 영상을 렌더링하지 않았다.

이 패키지는 실행 가능한 Windows 오프라인 RC이며 실제 Steam 게시를 뜻하지 않는다. CODE:SHIFT는 작업명, 한국 판매 계획 가격은 21,000원이다. 실제 초보자의 이해·재미·학습 성과와 소요 시간은 자동 완주와 별도로 확인해야 한다.
