## CODE:SHIFT에 적용할 세 가지 추천

현재 게임은 Windows 같은 데스크톱에서 동네 고객을 돕고, 선택 의뢰 뒤 자신의 첫 앱을 출시하는 구조다. 아래는 개선 후보이며 이 문서가 구현·테스트 완료를 의미하지 않는다. 기존 [비교 기록](benchmark-2026-10-10.md)에 적힌 기능은 신규 개발처럼 주장하지 않고 실제 현재 구현과 대조한다.

1. **고객의 현재 문제·확인한 상태·남은 행동을 검사 결과와 연결한다 (추천).**
   - 화면 근거: 2:21:00부터 3:21:20까지의 표본에 Part 8의 넓은 한 줄 목표가 계속 보이며, 3:05:45에는 여러 앱이 겹쳐도 목표는 가려지지 않는다. 따라서 개선의 중심은 목표 위치가 아니라 구체적인 조건·중간 결과의 연결이다. 자막 보조: 2:36:42–2:36:59, 3:05:49–3:05:56, 3:09:46–3:09:55에 방향 확인 부족이 명시된다.
   - 적용: 창 밖의 현재 목표를 유지하고, 마지막 검사에서 확인한 파일/기능 상태와 아직 충족하지 않은 고객 조건을 짧게 보여 준다. 예: “주문 화면은 열렸어요. 3잔의 합계가 9,000원이 되어야 해요. 지금은 3,000원이에요.” 수동으로 관련 앱/파일을 열어 조사하게 한다. 답안·전체 명령의 자동 적용 없이 도움말을 직접 열 수 있게 한다.
   - 핵심 조건/불이익: 이미 완료한 조건의 판정은 사실과 일치해야 한다. 정보를 너무 많이 항상 노출하면 조사 재미가 줄므로 고객의 요구·현재 결과를 기본으로, 해결 예시는 선택 힌트로 둔다. 원본의 정답 대상이나 게임 버그를 안다는 가정은 필요하지 않다.

2. **현재 파일·폴더와 실패 조건을 설명하고, 올바른 결과는 같은 기준으로 인정한다.**
   - 화면 근거: 13:45에는 파일에 `cd`를 적용한 디렉터리 오류가 보이며 13:50→14:00의 올바른 폴더 이동·내용 읽기 뒤 목표가 체크된다. 48:48 핸드북에는 전체 명령 예시가 있지만 49:18 터미널에는 옵션을 독립 명령으로 쓴 오류 기록이 있다. 1:09:00→1:10:30은 검색어의 과도한 구체성에 따라 결과가 달라진다. 이들은 구체적인 입력 의미·오류 설명의 근거다. **숨은 고정 순서 강제는 실제 화면으로 증명되지 않았다.**
   - 적용: 실제 입력하는 제한 코드/터미널을 유지하면서, 파일 값·함수의 다양한 입력 결과·준비된 앱 상태를 검사한다. 경로를 조사하는 명령 자체가 학습 목표인 의뢰에서는 “폴더를 직접 확인하는 연습”이라고 미리 명시하고, 일반 고객 의뢰에서는 동일한 상태를 만드는 합법적인 다른 순서를 인정한다. 제출 형식 오류는 “틀렸어요” 대신 요구한 형식·누락한 항목을 알려 준다.
   - 핵심 조건/불이익: 게임 결과 검사는 실제 동작과 고객 조건을 유지해야 한다. 단일 고정 답안을 느슨하게 문자열 비교하는 방식으로 바꾸면 우회만 쉬워질 수 있다. 도움말의 파일명·예시는 실제 열리는 파일과 일치시킨다. 3:05:45의 `net_tree.py`/`pyUserEnum.py` 불일치는 복사해 넣은 안내가 새 상황과 어긋나는 위험을 실제로 보여 준다.

3. **짧은 납품→고객 변화→보상과 선택 의뢰→첫 출시를 명확히 연결하고, 기억할 내용을 다시 찾을 수 있게 한다.**
   - 화면 근거: 1:15:00 채팅의 인물·상황 설명→1:24:00 기기 도식→1:30:00 숙박자 문서→1:36:00 첨부와 상황 회신으로 장기 조사가 이어진다. 2:04:30에는 새 파일과 메일 알림, 2:18:00에는 기술 결과와 채팅이 함께 보인다. 자막 보조: 25:45–25:53의 고객 반응과 보수, 1:14:05–1:15:29의 자발적인 스토리 선택, 1:29:44–1:29:52의 인물 이름 상실, 2:50:55–2:51:13과 3:19:24–3:20:46의 회상 부담.
   - 적용: 검사 성공 뒤 실제 고객의 수정 전/후 화면, 납품 완료와 크레딧, 꾸미기/도구 상점, 다음 선택 의뢰와 개인 출시 진척을 이어 보여 준다. 고객 조건·배운 명령·중요 파일을 사용자가 직접 다시 여는 작업 메모로 제공하고, 필수 진행과 추가 일감을 분명히 표시한다. 선택 힌트를 자동으로 펼치지 않는다.
   - 핵심 조건/불이익: 메모가 정답 목록이 되면 추론이 사라지므로 배운 목적·형식·현재 단서 중심으로 쓴다. 2:01:14–2:02:22와 2:23:40–2:23:48의 부담을 고려해 초보자의 첫 앱 출시를 시간제 정확한 타이핑·금전 손실로 묶지 않는다. 기존 보상/회고 화면과 중복되는 새 창을 늘리기보다 현재 흐름의 연결을 보완한다.

## 이 기록으로 주장하지 않는 것

- 전체 3시간 21분 화면 연속 시청, 음성 청취 또는 게임 완주.
- 레퍼런스 게임 내부의 정확한 판정 로직, 오류/버그, 명령 철자, 힌트 UI의 실제 존재·부재.
- 한 스트리머의 발화를 모든 초보자의 실제 플레이 시간·실패율·만족도로 일반화한 결과.
- 우리 게임의 개선 완료, 사람 대상 플레이테스트 완료, 나머지 제공 영상 전체 검토.

화면 검토에서 자막의 설명과 다른 사실이 확인되면 화면 사실을 우선하고, 이 문서의 해당 문장을 가설 또는 오해 사례로 수정한다.
