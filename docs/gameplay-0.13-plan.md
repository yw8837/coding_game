# 0.13 — 고르는 의뢰, 여러 풀이, 내 작품

사용자 요청: 지루한 반복을 줄이고 자유도를 넓힌다. 다른 코드도 고객이 원하는 결과를 만족하면 인정한다. 코딩 학습용 공개 엔진과 저장소의 설계도 참고한다.

## 구현 범위

- 카페 입문 3장은 유지한다. 이후 각 구역의 6개 중 4개를 자유롭게 골라 진행한다. 총 18개 중 12개로 최종 프로젝트에 도달하며, 나머지의 보상과 접근은 유지한다. 다음 의뢰 제안은 아직 목표를 채우지 않은 구역을 우선한다.
- 빵집 계산, 도서관 대출, 연락처 정리, 배달비, 축제 정산 의뢰에 제한 JavaScript 함수 풀이를 제공한다. 기존 설정/데이터 편집도 유지한다. 양쪽은 같은 보상을 받는다. 코드 모드와 초보자용 부분 편집을 혼동하지 않는다.
- JavaScript는 기존 AST 인터프리터 안에서만 실행한다. 사용자 소스를 eval/Function/Node로 실행하지 않는다. 정상·경계·변형 입력의 출력을 판정하고, 사용자 입력으로도 실험한다. 전체 JavaScript 지원으로 홍보하지 않는다.
- 최종 프로젝트에는 개인 내용, 항목, 분류, 색, 배치를 저장한다. 검색·분류·문의 동작은 저장 파일의 내용과 일치해야 한다. 화면 폭은 하나의 정답 문자열보다 좁은/넓은 화면에서 맞는지 검사한다.
- 힌트는 수동으로만 열며 실패해도 보상 손실이 없다. 클릭만으로 전체 의뢰를 해결하는 기능은 추가하지 않는다.

## 호환성

- 저장 키, 기존 파일, 완료 보상, 과거 공개 프로젝트를 유지한다.
- 엔딩을 볼 때의 의뢰 목록을 별도 기록한다. 그 뒤 추가 의뢰를 해결해도 엔딩이 바뀌거나 불러오기가 실패하지 않는다. 기존 18개 완주 저장은 이전 결말을 그대로 인정한다.
- 이전 3파일 프로젝트는 그대로 읽고, 새 project.json은 새 시작에만 생성한다.

## 검증 기준

- 서로 다른 12개 선택 경로, 다음 구역 잠금, 선택 의뢰 보상, 엔딩 이후 저장 왕복.
- 의뢰별 서로 다른 올바른 JS 풀이와 잘못된 상수·경계 풀이, 실행 예산·전역 접근 거부.
- 기존 설정 경로와 신규 코드 경로, 코드 모드 전환과 초안 보존, 터미널 편집·검사.
- 한·영·일 UI, 수동 힌트, 실제 내용에 따른 프로젝트 미리보기, 반응형 화면, 이전 저장.
- 웹 및 Windows RC에 같은 소스를 넣는다. 인간의 재미·이해도와 Steam 출시 승인은 별도 확인 대상이다.
