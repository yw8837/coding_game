# CODE:SHIFT — playable first release

The approved concept is a coding simulator: all operating systems, tools, package installs, repositories, processes and networks are game state. No player command reaches the host shell or the real internet.

## Product

A Korean virtual desktop with Grome (그롬), COOCLE search, CatHub repositories, a terminal, editor, API client, server panel, NPC hints and an explicit contract/reward loop. The visual direction is an ink-blue workstation with mint execution states, amber quest markers and warm paper inside the client's cafe website. The game opens directly on the desktop and first contract.

Three connected contracts grow Mono Cafe: repair a mobile menu; fix JavaScript order totals; bring a Python menu API online on a simulated Ubuntu server. This is a playable opening chapter, not a claim that the full beginner-to-upper-intermediate curriculum is finished.

## State contracts

- Packages belong to a machine; npm dependencies belong to a project. Current paths and missing manifests produce distinct errors.
- File edits, staged snapshots, commits, remote pushes, pull requests, merged snapshots and deployed snapshots are distinct.
- Browser previews, API requests, repository pages and rewards use the same state.
- Mobile CSS checks measure the rendered page in isolated frames. JavaScript arithmetic is evaluated by a bounded parser; unsupported syntax reports its scope. Python API exercises support the supplied route/configuration subset and identify unsupported edits.
- Rewards are granted once per contract only after its tested, reviewed snapshot is deployed.
- Saves are explicitly local to this browser. Corrupt saves recover visibly; reset requires confirmation.
- Authored NPC hints work offline. No live LLM is claimed. A local LLM tutor remains a future optional integration; execution/grading stays deterministic.

## Delivery

Build in the dedicated fresh Sites checkout and publish a private playable URL. Source, design and verification records stay in its source repository. Browser QA is performed only using a supported permitted preview path. No real account, API key, server provisioning or external repository is part of gameplay.
