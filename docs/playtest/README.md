# CODE:SHIFT 0.10 실제 초보자 플레이 테스트

이 폴더는 실제 플레이를 준비하고 관찰을 기록하는 도구입니다. 현재 테스트 결과나 초보자 검증 성공을 주장하지 않습니다. 자동 UI 테스트, 개발자 플레이, 도움받은 완료를 초보자의 독립 이해로 바꾸어 해석하지 않습니다.

1. 먼저 사용자 본인이 새 테스트 프로필에서 20~30분 플레이합니다. 기록 구분은 **개발자·사용자 본인 플레이**로 남깁니다.
2. 그다음 서로의 플레이를 보지 않은 초보자 3~5명이 같은 버전을 각자 처음 플레이하게 합니다. 코딩 경험은 참가자가 말한 내용을 기록합니다. 경험 미확인은 확인한 초보자 수에 포함하지 않습니다.
3. [진행 안내](protocol.md)를 읽고 [관찰 양식](observation-template.md)과 [사후 질문](questionnaire.md)을 준비합니다.
4. [오프라인 기록 도구](../../tools/playtest/index.html)를 엽니다. Windows 탐색기에서 `tools/playtest/index.html`을 더블클릭해도 됩니다. `index.html`, `data.js`, `kit.js`, `kit.css`를 같은 폴더에 유지하세요. 서버, 설치, 계정, 인터넷은 필요 없습니다.
5. 참가자별 새 기록을 만들고 P001처럼 익명 코드만 사용합니다. 기록을 입력한 뒤 JSON 백업과 CSV 보고서를 내보냅니다. 결과를 함께 검토하려면 익명 보고서와 실제 막힌 지점을 공유하면 됩니다.

## 저장을 먼저 보호하기

기존 게임에서 설정 → **백업 내보내기**를 먼저 실행하세요. 백업 파일이 생겼는지 확인하고 기존 저장을 보관합니다. 실제 플레이 저장에 덮어쓰거나 초기화하지 않습니다.

- 웹 게임: 새 브라우저 **프로필**에서 테스트합니다. 참가자마다 별도 프로필을 쓰면 이전 플레이가 섞이지 않습니다. 비공개 창은 닫으면 저장이 사라질 수 있으므로 이어하기를 관찰하려면 프로필이 낫습니다.
- Windows 데스크톱 게임: 별도 Windows 테스트 계정에서 플레이합니다. 같은 계정의 저장 초기화를 새 세션 준비 수단으로 쓰지 않습니다.
- 이어하기: 테스트용 저장을 그대로 두고 같은 테스트 프로필·계정에서 다시 실행합니다. 테스트가 끝나면 테스트용 저장과 기록을 원하는 경우 별도로 백업합니다.
- 기록 도구는 게임 저장을 읽거나 수정하지 않습니다. 도구 자체의 `codeshift-playtest-kit-v1` 데이터만 이 브라우저에 저장합니다.

## 파일과 보고서

JSON은 원본 보관에 사용하고 CSV는 표로 읽는 데 사용합니다. 두 형식 모두 도구에서 다시 가져올 수 있습니다. 가져오기는 버전·열 구조·항목·범위·크기를 검사한 뒤 기존 기록에 **추가**합니다. 같은 기록 ID의 내용이 다르면 기존 내용을 덮어쓰지 않고 오류를 표시합니다. 수정한 CSV의 공통 세션 값은 해당 세션의 모든 행에 동일하게 들어 있어야 합니다.

한 세션의 CSV에는 관찰 항목 7행이 들어 있습니다. 참가자 수를 행 수로 세지 마세요. 같은 참가자의 재방문은 같은 익명 코드를 사용하되 새 기록으로 만들면 됩니다. 중복 인원은 코드로 구분합니다. 보고서 최대 크기는 2MB, 기록은 최대 100회입니다. 빈칸과 `untested`는 누락 또는 미관찰이며 성공이 아닙니다. Excel에서 식으로 읽힐 수 있는 메모에는 보호 문자가 추가되고 이 도구의 재가져오기는 이를 복원합니다.

로컬 파일 주소의 저장 기능은 브라우저 정책에 따라 막힐 수 있습니다. 이 경우 화면의 안내를 확인하고 **창을 닫기 전에 JSON을 내보내세요**. 자동 저장만 믿지 마세요. 모든 기록을 제거하려면 먼저 백업한 뒤 해당 브라우저의 이 파일에 대한 사이트 데이터를 수동으로 지우세요. 이 도구에는 게임 초기화나 참가자에게 메시지를 보내는 기능이 없습니다.

## 해석 범위

3~5명은 반복되는 막힘과 다음 수정 우선순위를 찾는 작은 관찰 표본입니다. 모집단 전체의 성공률이나 학습 효과를 확정하지 않습니다. 재미·이해·다시 할 의향은 자체 1~5 문항이며 검증된 척도가 아닙니다. 평균만 보지 말고 참가자별 응답과 실제 행동 근거를 함께 읽습니다.

본인 플레이와 독립 초보자 기록을 분리하세요. 완료해도 이유를 설명하지 못할 수 있고, 말로 설명해도 조작을 수행하지 못할 수 있습니다. **완료·도움 사용·설명·새 상황 적용**을 각각 기록하세요. [검토 양식](review-template.md)의 빈칸은 실제 관찰 이후에만 채웁니다.

도구의 데이터 검증 테스트: 프로젝트 루트에서 `node --test tools/playtest/data.test.cjs`. 이 명령은 실제 초보자 플레이 테스트가 아닙니다.
