# Localhost Hero 일본어 첫 플레이 검토

2026년 11월 22일, 개발 작업본에서 확인했다. 플레이어의 43분 13초 영상은 일본어 자동 자막으로 처음부터 끝까지 흐름을 확인하고, 코드와 결과가 엇갈린 두 장면은 화면을 따로 확인했다. 발화 시각은 자동 자막 기준의 근삿값이다. 아래 재현은 영상 촬영 당시의 설치본과 현재 개발본을 구별한다.

개발본에서 재현한 실패와 수정 후의 성공을 한 쌍으로 확인했다. 메뉴의 이름을 일본어로 쓰거나 플레이어가 직접 이름을 지어도, 레이아웃을 고쳤다면 통과해야 한다. 반대로 빈 메뉴, 가려진 항목이나 조작할 수 없는 버튼까지 통과시켜서는 안 된다.

이 영상 한 편으로 전체 이용자의 이탈률이나 수정 후 만족도는 알 수 없다. 특히 첫 의뢰를 처음 보는 일본어 이용자가 도움 없이 완주하는지는 다음 실제 첫 플레이에서 확인할 항목이다.

## 11월 22일 최종 개발본 검증

- 최종 오프라인 렌더러를 Chrome 새 프로필에서 열고 일본어 설정 화면에서 중국어 간체로 변경했다. 새로고침 후에도 선택이 유지됐다. 첫 메시지, 의뢰 수락, 중국어 준비 단계, 터미널 명령 여섯 개를 거쳐 점포명을 莫诺咖啡馆으로 직접 입력하고 CSS 폭을 100%로 수정했다. 손님 검사를 통과한 뒤 첫 의뢰를 전달했고 저장 데이터의 완료 기록을 확인했다. 페이지 실행 오류는 0건이었다.
- 일본어·중국어 터미널에서 실패 항목을 읽고 해당 파일을 열어 수정한 뒤 재검사하는 경로가 모두 통과했다. 실제 브라우저 미리보기 회귀 검사는 19개가 통과했다.
- 최종 소스에서 게임 단위 테스트 427개, 타입 검사, 전체 ESLint 및 의존성 검사가 통과했다. 오프라인 데스크톱 렌더러 빌드도 성공했다.
- 통합 검증 명령은 이 D 드라이브에서 린트 시간 제한으로 중단됐다. 각 단계를 별도로 실행했고 데스크톱 테스트 41개 중 37개가 통과했다. 나머지 4개는 exFAT에서 Windows 정션을 만들지 못해 테스트 준비 단계에서 실패했다. 이 네 검사는 정션을 지원하는 환경에서 다시 확인해야 한다.
- 스팀에 현재 공개된 실행 파일 및 웹 서비스에는 이번 개발본을 배포하지 않았다.
