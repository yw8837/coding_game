# 첫 플레이 진행 안내 · 한국어

목표는 “설명 없이 어디로 갈지 찾는가, 한 조작과 결과의 관계를 이해하는가, 계속하고 싶은가”를 실제로 관찰하는 것입니다. 현재 0.10 기본 흐름은 **빈 바탕화면 → 메시지 → 카페의 선택 조작 → 연산자 입력 → 동네 의뢰**입니다. 모두 끝내는 시험이 아니며 20~30분 동안 도달한 곳까지만 기록합니다.

## 준비

- 사용자가 먼저 같은 흐름을 혼자 플레이하고 본인 기록을 남깁니다. 여기서 발견한 사용 환경 문제는 초보자 세션 전에 수정·준비합니다.
- 초보자 3~5명은 서로의 플레이와 답을 보지 않도록 각각 진행합니다. 설명 자료·공략·미리 채운 답안을 보여 주지 않습니다.
- 같은 버전·같은 기본 “함께 배우기” 설정을 사용합니다. 언어는 참가자가 편하게 읽는 것으로 선택하고 화면 크기·입력 장치·버전을 전체 메모에 남깁니다. 본인과 초보자를 따로 표시합니다.
- 기존 저장을 설정에서 백업하고 새 브라우저 프로필 또는 별도 Windows 테스트 계정을 준비합니다. 기존 플레이를 초기화하지 않습니다.
- 녹화가 없어도 진행할 수 있습니다. 화면 녹화, 화면 캡처, 음성 녹음은 사용할 방식별로 먼저 설명하고 각각 동의를 받습니다. 거절해도 참가할 수 있습니다. 이름·나이·연락처를 기록하지 않습니다. 화면에 개인 정보가 보이면 기록을 중지합니다.

## 시작 안내 · 2분

다음 문장을 그대로 읽어도 됩니다.

> “이 게임을 처음 하는 사람이 어디서 헷갈리는지 보고 싶어요. 당신 실력을 평가하는 시험은 아닙니다. 평소처럼 해 보시고, 가능하면 지금 생각하는 것을 말해 주세요. 말을 계속할 필요는 없어요. 처음에는 제가 조작이나 답을 설명하지 않을게요. 언제든 쉬거나 그만둘 수 있고, 이유를 말하지 않아도 됩니다. 이름이나 나이는 기록하지 않겠습니다. 짧은 익명 메모를 남겨도 괜찮을까요?”

동의하지 않으면 세션을 진행하거나 관찰 결과를 수집하지 않습니다. 도구에서 참여 동의를 확인한 뒤 시작합니다. 녹화를 쓰는 경우에는 별도로 어떤 화면·음성이 기록되고 누구와 검토하며 언제 삭제하는지 설명하고 동의를 받습니다. 동의 방법·범위를 전체 메모에 익명으로 남깁니다.

## 자유 플레이 · 15~20분

“시작해 보세요”라고만 안내합니다. 처음 **3분 동안** 클릭할 위치, 메뉴 이름, 코드, 정답을 알려주지 않습니다. 참가자의 질문에 “어떤 부분이 헷갈리는지 말씀해 주세요”라고 답할 수 있지만 다음 조작을 지정하지 않습니다. 진행자가 실수로 힌트를 줬다면 시각과 정확한 말을 기록합니다.

3분 후에도 먼저 관찰합니다. 반복해서 같은 행동을 하거나 더 진행하지 못하는 모습을 보이면 다음처럼 중립 질문을 한 번 합니다.

> “지금 어떤 일이 일어나기를 기대하고 있나요?”
> “화면에서 다음으로 해 볼 만한 것이 보이나요?”

완료하면 **중립 질문 후 완료**로 기록합니다. 클릭할 위치나 바꿀 값을 알려 주었다면 **힌트·직접 도움 후 완료**입니다. 게임 안의 추가 힌트·선택 도움을 사용한 경우도 기록하고 도움 출처를 `게임`으로 선택합니다. 시작부터 보이는 기본 단계 안내는 기본 흐름으로 취급하며, 참가자가 선택적으로 여는 추가 도움과 구분합니다.

참가자가 도움을 요청하면 계속 막힌 상태를 강요하지 말고 원하는 만큼 도와줍니다. 먼저 “힌트를 원하시나요, 조금 더 해 보시겠어요, 그만할까요?”라고 묻습니다. 답을 준 뒤 성공해도 독립 완료로 기록하지 않습니다. 중단·휴식 요청은 즉시 따릅니다. 30분이 되면 다음 의뢰 완료를 강요하지 않고 마칩니다.

각 지점에서 남길 것:

| 지점 | 실제 관찰할 행동 | 관찰하지 못했을 때 |
| --- | --- | --- |
| 빈 바탕화면 | 어디서 시작할지 스스로 찾는 행동 | 미관찰 |
| 메시지 | 요청을 읽고 작업으로 이어가는 행동 | 미관찰 |
| 카페 | 선택 조작 후 화면·값 변화 확인 | 미관찰 |
| 연산자 | 입력·검사 후 결과를 연결하는 행동 | 미관찰 |
| 동네 의뢰 | 한 부분 수정, 결과 확인, 명시적 검사 | 미관찰 |
| 새 상황 | 다른 숫자·조건에서 예측·설명 또는 조작 | 미관찰 |
| 이어하기 | 테스트 저장을 다시 열어 이어갈 곳 찾기 | 미관찰 |

멈춤은 “헷갈림” 한 단어 대신 **화면, 행동, 시간, 참가자의 말**로 적습니다. 예: 시간 표시와 함께 “메시지를 닫은 뒤 같은 바탕화면 아이콘을 세 번 열었다. 다음 의뢰 위치를 물었다.” 이는 양식 사용 예이며 실제 결과가 아닙니다.

## 새 상황 과제 · 3분

참가자가 실제로 만난 개념 하나만 고릅니다. 원래 문제와 다른 숫자·조건을 제시하고 **먼저 예측과 이유**를 듣습니다. 새 값의 답, 연산자, 클릭 위치를 제공하지 않습니다. 도달하지 못한 개념은 건너뛰고 미관찰로 남깁니다.

- 계산을 만났다면: “상품 한 개가 2,500원이고 4개를 산 상황이라면, 계산대에 어떤 결과가 나와야 하나요? 이전 파일의 어떤 부분을 바꿔야 할지 설명해 주세요.” 진행자는 답을 읽어 주거나 연산자를 보여 주지 않습니다.
- 화면 너비를 만났다면: “다른 사람이 더 작은 화면으로 볼 때도 내용이 들어가게 하려면 어떤 값을 살펴볼까요? 그 값을 바꾸면 어떤 일이 일어날까요?” 특정 값이나 정답 선택지를 보여 주지 않습니다.
- 조건을 만났다면: 방금 다룬 의뢰와 다른 경계 숫자를 말하고, 경계에 딱 맞는 경우와 넘는 경우를 어떻게 처리할지 설명하게 합니다. 규칙의 정답을 먼저 말하지 않습니다.

진행자는 자기 메모에 기대 행동을 미리 정하되 참가자에게 보여 주지 않습니다. 화면에서 실제 변경을 시도했다면 그 행동을 기록하고, 말로만 설명했다면 **구두 과제**로 명시합니다. 말로 설명한 결과를 실제 편집 성공으로 바꾸어 기록하지 않습니다. 답을 알려 준 뒤 반복한 설명은 이해의 독립 근거로 쓰지 않습니다.

## 사후 질문과 마무리 · 2~5분

[질문지](questionnaire.md)의 세 문항과 자유 질문을 묻습니다. “재미있었죠?”처럼 긍정 답변을 유도하지 않습니다. 미응답을 중간값으로 넣지 않습니다. 실제 총 시간과 마지막 도달 화면을 남기고 JSON·CSV를 내보냅니다. 녹화가 있다면 동의한 보관·삭제 약속을 따릅니다. 테스트용 저장은 이후 이어하기가 필요하면 그대로 보관합니다.

세션 사이에는 참가자별 발견을 기록하되 다음 참가자에게 해법을 먼저 설명하지 않습니다. 버전을 수정했다면 수정 전후 세션을 섞어 같은 조건의 성공률로 계산하지 않습니다.
