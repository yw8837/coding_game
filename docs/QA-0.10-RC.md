## 검토와 증거

소스 검토에서 발견한 대문자 H1 편집 문제와 상점 이동을 덮어쓰던 이전 화면 요청을 수정했다. 새 시작·계속·초기화 때도 화면 요청이 초기화된다. 재검토자는 해당 범위에 남은 P1/P2를 보고하지 않았다. 별도 소스 검토는 실행 검사를 대체하지 않는다.

카페 문제 관찰·주문, 동네 학습, 최종 프로젝트, Ghrom 화면을 실제 스크린샷으로 검토했다. 좁은 화면에서는 390px 문서 가로 넘침을 검사했다. 화면을 줄이기 전에 연 퀘스트 패널이 일부 테스트 스크린샷에 겹쳐 있으므로 그 이미지를 정돈된 모바일 홍보 화면으로 사용하지 않는다.

- `output/0.10-qa/`: unit/desktop-unit/typecheck 로그, coach/learning/release/terminal/wallet 보고서, native/packaged/desktop-build/package 로그, offline-package-report.
- `output/steam-qa/`: career-report, tools-report, native-report, packaged-report.
- `output/pc-qa/final-smoke.json`: 소개 페이지·빈 바탕화면·터미널 도움말 검사.

이전 실행의 실패 캡처는 진단 자료이며 최종 성공 보고서와 구분한다. 학습·터미널·소개 화면을 바꾼 뒤 남아 있던 오래된 선택자·기대 문구를 수정하고 해당 E2E를 다시 실행했다. 이 테스트 실패만으로 게임 프로세스 충돌이 발생했다고 판단하지 않는다.

## 검증의 한계

자동 완주는 화면에 있는 예시·힌트와 도움 기능을 사용한 기능 검사다. 비전공 15세 사용자가 혼자 이해하고 즐기며 코딩을 익힌다는 증거는 아니다. 이번 UI 완주는 balanced 결말이며 다른 두 결말 조건은 단위 검사 범위다.

ESLint의 기존 `next/dist/compiled/babel/eslint-parser` 해석 문제는 이번 작업에서 해결하거나 재검사하지 않았다. 따라서 lint 통과로 주장하지 않는다. 데스크톱 빌드에는 약 1,002KB의 JS 청크 크기 경고가 남는다. PNG 경로 경고 뒤 빌드 스크립트가 자산을 복사하며, 실제 패키지에서 동일 파일 포함을 확인했다.

기본 패키지와 QA 패키지는 QA 플래그가 다르다. 동일 파일 확인과 QA exe 실행은 별도의 깨끗한 Windows PC에서 배포판을 검증한 것과 다르다. 최소 사양·플레이 시간·접근성 사용자 검사·실제 초보자 플레이는 미검증이다.

실제 Steam App ID·Steam 업적·Cloud·SteamPipe 업로드·스토어 심사·실행 파일 서명·공식 연령 등급·가격 적용은 완료하지 않았다. 이 전달물은 Windows 오프라인 RC다. 21,000원은 한국 판매 계획 가격이며 CODE:SHIFT는 작업명이다. 기존 42초 영상은 0.9 영상이고 새로 렌더링하지 않았다.
