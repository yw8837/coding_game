# 홍보영상·음악 수정 검증 — 2026-10-10

게임 버전은 **0.13.2-rc.0**이다. 이번 변경은 홍보영상·포스터·소개 페이지 및 관련 제출 자료에 한정된다. Windows 설치본 재빌드나 Steam 출시 완료를 뜻하지 않는다. 기존 게임·native·패키지 검증은 [0.13.2 QA](QA-0.13.2-RC.md)에 보존한다.

## 편집 결과

- 시작: **고장 난 계산대. / 해결 보상 200 cr.** 실제 빵집의 6개 계산 결과 12,600원과 기대값 10,000원을 보여 준다. 카페 첫 의뢰 보상과 혼동하는 문구를 제거했다.
- 수리·검사·납품 보상 → 보조 모니터 구매와 사용 → 의뢰 선택과 구역 개방 → 내 포트폴리오의 게임 안 1.0.0 배포 순서다.
- 밝은 크림색 배경을 남색 `#101c28`로 바꾸고, 짧은 문구와 절제된 파랑·민트·따뜻한 강조색을 사용한다. 실제 게임 UI의 픽셀은 재작성하지 않는다.
- 마지막 3.75초에도 실제 만든 앱을 남기고 **내 첫 / 출시.**, **첫 의뢰 시작하기**를 보여 준다. Steam이나 실제 인터넷 서비스 출시를 주장하지 않는다.
- 새 포스터 **버그 고치고 / 내 앱 출시**는 기존 가상 캐릭터와 작업실을 참고한 AI 생성 홍보 일러스트다. 게임 스크린샷이나 Steam 캡슐이 아니다. 1280×720 원본 크기와 320×180 축소본을 시각 검토했다.

## 음악과 믹스

기존 Realizer 대신 Kevin MacLeod의 **Voxel Revolution**을 사용한다. 공식 출처와 CC BY 4.0, 저작자·원본 링크·변경 사항은 `public/media/ATTRIBUTION.txt`, 소개 페이지 및 MP4 메타데이터에 남긴다. 자세한 취득 근거는 [음악 검토](reviews/trailer-music-2026-10-10.md)에 있다.

- 원본 MP3 SHA-256: `9977d93c698abacc29e5da7ff0bccee2b8f6de47ed7e567cb0f1ed9b7564f74e`.
- 15.7577–47.233109836초 구간, 122→128 BPM, 피치 유지, 결과 30초/64비트.
- 시작부터 파형이 강한 구간을 쓰고, 수리 직전에 짧게 음악을 낮춘다. 개인 앱 장면부터 정규화 전 음악 레벨을 12% 높인다.
- 클릭·임팩트·성공 효과음의 레벨을 낮춰 음악과 섞는다. 실제 게임 오디오의 실시간 녹음이 아니라 편집 효과음이다.
- 마지막 한 마디(1.875초)는 부드럽게 감쇠한다. 원곡의 자연스러운 종지라고 주장하지 않는다.
- 네 최종 MP4 모두 **−15.88 LUFS / −1.69 dBTP**, AAC 48 kHz 스테레오. 전체 디코딩 오류 없음.

## 렌더·정적 검증

모든 영상은 30초, 900프레임, 30fps, H.264 yuv420p다. 가로는 1920×1080, 세로는 1080×1920. 소스 범위·연속 프레임·최대 8배 속도·원본/캡처 근거/EDL/출력 해시 결합을 검사했다. 실제 0.13.2 한국어 화면 위에 KO/EN/JA 편집 문구를 얹었으며 언어별 게임 UI 촬영본은 아니다.

실행 근거는 `output/trailer-polish/`의 렌더 로그, `final/*-qa.json`, `edit/edl-current.json`, `edit/review/`에 있다. 4개 컨택트 시트와 가로 시작/마지막 장면을 열어 문구·색·배치·실제 결과 표시를 검토했다. 세로는 실제 화면이 가로여서 넓은 UI 장면의 작은 본문 가독성이 제한되며 큰 편집 문구가 목표와 결과를 설명한다.

변경된 소개 페이지 ESLint(경고 0), 전체 TypeScript 검사, 렌더러와 QA 스크립트 Python AST, `git diff --check`를 통과했다. 힌트·세이브·런타임·게임 판정은 이번에 변경하지 않았다.

## 웹 검증

프로덕션 빌드가 성공했고 `final-smoke`는 11.64초에 종료 코드 0으로 통과했다. KO/EN/JA 3개 경로에서 1920×1080·30초 영상 재생과 16초 탐색, 1280×720 포스터 디코딩, 언어별 미디어 경로, Voxel Revolution 원본 링크와 출처 파일, canonical을 검사했다. 새 빈 프로필에서 창 없는 바탕화면으로 시작하고 각 언어의 터미널 `help`가 동작했다. 페이지 오류는 0개였고 소유한 서버는 종료했다. 한국어 소개 페이지의 실제 렌더링 스크린샷도 검토했다.

근거: `output/trailer-polish/qa/build.log`, `web-run.json`, `final-smoke.json`, `about-video-{ko,en,ja}.png`. 빌드에는 기존 Vinext의 일부 경로 정적 분류 안내가 남아 있다. 이 안내를 오류 0개라고 숨기지 않으며, 실제 소개·게임 경로는 production 브라우저 검사로 확인했다.

`output/trailer-current/`와 `output/trailer-rebuild/`, 기존 `D:/코딩게임/출시자료/0.13.2-RC`는 역사 자료다. 새 결과는 `output/trailer-polish/final/`와 별도 영상 수정 전달 폴더로 제공한다.
