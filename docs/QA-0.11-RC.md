## 릴리스 확인

최종 보안 수정과 의존성 갱신 후 Windows 네이티브 검사를 다시 통과했다. 카페 3장·동네 의뢰 18개·최종 배포와 엔딩, 코드 의뢰·터미널 파일 실행·달력, 종료/재실행 저장 복원, 가져오기 시 편집 대상 초기화, 네이티브 백업 내보내기와 언어 선택, 손상된 본 저장의 백업 복구를 검사했고 page error는 0건이었다. renderer에서 host `require`와 `process`는 노출되지 않았다.

QA 실행 폴더를 새로 빌드하고 실제 실행해 일본어 설정과 저장/재실행을 확인했다. 이어서 전달용 오프라인 폴더를 다시 빌드했다. 두 패키지의 renderer 및 main 보조 파일 18개가 동일하고, 전달용 QA 플래그는 false다. Node 실행·환경 옵션·CLI 디버거를 막는 fuse와 ASAR 무결성 설정, 동봉 라이선스 53종 manifest, 아트 4장의 원본 일치를 확인했다. Steam AppID는 null이며 다른 게임의 앱이나 Steam 모듈을 포함하지 않는다.

24초 0.11 터미널 영상은 실제 UI 자동 조작으로 촬영했다. 1920×1080·30fps·720프레임이며 전체 디코드와 음량 검사(−16.01 LUFS, −3.16 dBTP)를 통과했다. 9개 장면과 16개 컷 경계 샘플을 검토했다. 촬영 커밋은 `838525d730ee348563afc3612412ed5b4c2dde83`으로 최종 보안 패치 이전이며, 세부 provenance를 영상 README에 보존한다.

공개 배포와 GitHub/D: 동기화의 실제 식별자, ZIP CRC와 SHA-256 검증은 출하 후 전달 폴더의 `delivery-receipt.json`, `qa/zip-report.json`, `integrity-manifest.json`에 기록한다. 이 문서 자체를 배포 성공 증거로 사용하지 않는다.

## 증거와 검토

- `output/0.11-qa/`: unit 로그, 코드 의뢰·터미널·작업실·초보자 경로 보고서와 실제 스크린샷.
- `output/steam-qa/`: 최신 native/packaged 보고서. 이전 실행 파일은 역사적 자료다.
- `output/art-qa/offline-package-report.json`: 패키지의 QA 플래그·라이선스·자산·fuse·동일 파일 검사.
- `output/trailer-0.10/`: 실제 0.10 게임플레이 42초 영상 4종, 촬영 증거와 편집표·디코딩/음량 검사.
- `output/trailer-0.11-terminal/`: 새 터미널 티저와 별도 촬영·편집 증거.
- `docs/steam-launch/product-review.md`: 상점/게임 설명 검토와 수정 기록.

오류·예산·결과 크기의 저장 한도 불일치, JS 반복문/콜백 의미, 반례 보상 안내, 최신 코드 증거 무효화 등을 수정했다. 작업 파일 세 개를 전부 삭제한 뒤 초안으로 검사되는 문제는 작업 준비 기록을 저장해 해결했으며, 삭제 순서 6가지와 저장·복원을 검사했다. 다른 저장을 가져올 때 이전 편집 대상도 초기화한다. 셸 스크린샷은 정적 가시성 검사만으로 찾지 못한 겹침 문제를 발견하는 데 사용했다. 테스트 실패 캡처는 진단 자료로 남기되 납품 증거에서는 제외한다.

독립 UI 검토에서 출하 차단 결함은 발견하지 못했다. 390px 중앙 작업 앱은 내부 가로 스크롤을 사용하므로 마지막 아이콘이 경계에서 일부 보일 수 있다. 시계와 시작 메뉴는 유지되며 PC용 넓은 화면에서는 모든 기본 아이콘이 보인다.

## 검증의 한계

자동화는 공개된 예시·힌트와 반복 입력을 사용한다. 실제 초보자의 이해도·재미·학습 성과·플레이 시간은 아직 측정하지 않았다. 초보자 2–4시간, 경험자 1–2시간은 설계 추정이다. 상급 개발 역량의 습득을 보장하지 않는다. JavaScript 지원 문법과 데이터/연산 한도가 있으며 범용 Node 환경은 아니다.

개발/빌드 의존성 `braces`의 미패치 High 경고 1개와 lint 권고 68개가 남아 있다. 생산 의존성 및 데스크톱 의존성 감사는 각각 0건이다. 최신 desktop renderer의 JS 묶음은 약 1,226kB(압축 약 406kB)로 청크 크기 권고가 남는다. 실제 별도 Windows 장비의 최소 사양, 접근성 사용자 검사, 실행 파일 서명, Steam 계정·업적·Cloud·업로드·스토어 심사·가격 적용·공식 연령 등급은 미완료다. QA 패키지 실행과 기본 패키지의 파일 동일성 확인을 깨끗한 별도 PC 검증으로 표현하지 않는다.

현재 파트너 계정에는 이 게임의 AppID가 없으며 다른 게임의 5336990을 사용하지 않았다. 전달하는 Windows 빌드는 오프라인 RC다. 영상은 실제 UI를 QA 자동 입력으로 재현한 편집본이며, 인간 플레이 녹화나 Steam 출시 증명이 아니다. 전체 영상의 사람에 의한 청취 검토는 남아 있다.
