# CODE:SHIFT 0.11.1 RC — 직접 고치는 첫 의뢰

2026-10-10. CODE:SHIFT는 가제다. 이 업데이트는 초반 조작, 바탕화면, 알림과 홍보 영상을 다듬는다. 기존 카페 3장 → 동네 의뢰 18개 → 플레이어가 이름 붙인 동네 생활 웹앱 1.0.0 출시 → 마지막 편지의 흐름을 유지한다.

## 처음 플레이할 때

타이틀에서 시작하면 앱이 열려 있지 않은 파란 바탕화면이 나온다. 메시지에서 의뢰를 받고 카페의 잘못된 화면을 직접 확인한다. 첫 의뢰는 객관식 정답 버튼 대신 간판 이름 입력과 메뉴 너비 조절로 실제 HTML/CSS를 바꾼다. 다음 의뢰는 세 잔 주문의 잘못된 합계를 관찰하고 계산 기호를 직접 고친 뒤 새 손님 세 명의 주문으로 확인한다. 세 번째는 메뉴 주소를 직접 입력하고 주문 보관을 켠 뒤 실제 가상 API 요청으로 검사한다.

값을 저장해도 검사가 통과하지 않으면 의뢰 완료 보상은 지급되지 않는다. 빈 입력, 잘못된 값, 파일 저장 거절에 각각 피드백이 있으며 저장 실패를 성공으로 표시하지 않는다. 다음 작업이 열릴 때 성공 설명은 화면에 남고 불필요한 ‘다음’ 버튼은 없다. 힌트는 기본으로 닫혀 있고 사용자가 직접 열고 닫는다. 틀린 입력을 이유로 자동으로 펼치거나 정답을 채우지 않는다. 전체 코드 편집과 직접 터미널 작업도 계속 사용할 수 있다.

## 바탕화면과 작은 동작

| 배경 | 가격 | 저장 호환 |
| --- | ---: | --- |
| 기본 블루 | 무료 | 기존 기본 배경 ID 유지 |
| 햇살 해변 | 90 cr | 기존 amber 구매 유지 |
| 초록 정원 | 90 cr | 기존 violet 구매 유지 |
| 오피스텔 작업실 | 180 cr | 새 loft ID |

네 배경은 각각 다른 이미지다. 소유한 배경을 다시 적용할 때 크레딧이 들지 않으며 선택과 구매는 저장된다. 이름·설명·구매 알림을 한·영·일로 제공한다. 이미지 생성 원문과 해시는 [배경 출처](assets-wallpapers.md)에 남겼다.

해당 앱의 작업 내용이 실제로 보이면 반복되는 ‘해당 앱 열기’ 버튼은 접힌 현재 작업 안내로 바뀐다. 앱을 닫거나 최소화하거나 다른 창에 가리면 다시 이동 안내가 나온다. 제목줄만 드러난 창은 작업 가능한 창으로 보지 않으며, 다른 주소나 파일로 이동해야 하는 버튼은 유지한다. 메시지를 읽고 닫으면 새 메시지 알림이 사라지며, 아직 수락하지 않은 의뢰 안내는 남는다.

게임의 성공·보상·재시도 효과음을 밝은 음색으로 바꿨다. 음소거는 예약된 소리까지 중단하며 연속 클릭으로 소리가 과도하게 겹치지 않도록 제한한다. 배경 음악은 게임에 상시 재생하지 않는다.

## 30초 홍보 영상

계산대 고장 → 직접 코드 수정 → 맞는 합계 → 주문 도착 → 보상 → 카페 오픈 → 장비와 배경 구입 → 동네 의뢰 → 내 웹앱 출시의 결과를 보여 준다. 128 BPM에 맞춰 자막이 움직이며 밝은 음악을 사용한다. 한·영·일 가로 영상과 한국어 세로 영상을 제공한다. 영어·일본어 영상의 편집 자막은 번역되어 있고 게임 촬영 화면은 한국어다.

실제 UI를 자동 조작해 촬영했다. 후반은 기존 UI 플레이로 얻은 저장을 화면에서 가져오는 장면 전환이며 하나의 연속 플레이로 표현하지 않는다. 효과음은 편집 추가다. 영상의 1.0 출시는 게임 속 플레이어 웹앱의 출시다. 음악은 Kevin MacLeod의 Realizer, CC BY 4.0이며 공유할 때 동봉된 ATTRIBUTION.txt를 설명란에 함께 넣어야 한다.

## 전달 범위

React/TypeScript와 Vite로 묶은 동일 게임을 웹판과 Electron Windows x64 오프라인 RC로 제공한다. 플레이어는 Godot·Unity·Node 설치가 필요 없다. ZIP을 풀고 실행 파일과 동봉 파일을 함께 유지한다. 기존 저장을 임의로 초기화하지 않는다.

이 자료는 Steam 출시 완료를 뜻하지 않는다. 이 게임의 새 AppID, 등록·결제·스토어 심사·실제 Steam 기능 검증은 남아 있고 다른 게임의 5336990은 사용하지 않는다. 자동 검사는 실제 초보자의 재미·이해도·학습 성과를 대신하지 않는다. 별도 PC 최소 사양과 실행 파일 서명도 남아 있다. 개발/빌드 의존성 braces의 미패치 High 경고는 [보안 기록](security/README.md)에 유지한다.

최신 실제 검사 결과는 [QA-0.11.1-RC.md](QA-0.11.1-RC.md), 배포·ZIP·소스 식별자는 전달 폴더의 delivery-receipt.json과 integrity-manifest.json을 참고한다.
