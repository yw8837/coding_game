# CODE:SHIFT 0.9 RC — 동네가 보이는 작업실

2026-10-09. CODE:SHIFT는 작업명이며 Steam 한국 판매 계획 가격은 21,000원이다. 이번 버전은 기존 캠페인에 환경 이미지, 인물, 의뢰 지도와 납품 피드백을 연결한다. 실제 Steam 출시 완료를 뜻하지 않는다.

## 화면과 플레이

- 타이틀에 저녁 작업실 그림을 적용했다. Start/Continue 뒤에는 아무 앱 창도 열리지 않은 바탕화면이 나온다. 시작 메뉴, 작업 표시줄과 창 조작은 유지한다.
- 바탕화면과 의뢰 지도는 같은 동네를 보여 준다. 지도에서 장소를 선택하면 고객, 문제, 보상과 의뢰 열기 버튼이 표시된다. 18개 의뢰는 기존 캠페인의 실제 기록에 연결된다. 앞 장의 여섯 의뢰를 모두 전달해야 다음 장이 열리고, 완료한 장소에는 도장이 남는다.
- 메시지함에 지우와 민서의 초상화를 넣었다. 카페 그림에는 메뉴·결제·주문 완료 상태를 겹쳐 보여 주고, 세 장 완료 뒤 OPEN 표시와 불빛이 바뀐다.
- 실제 납품 성공 뒤 짧은 보상 표시와 효과음이 나온다. 표시가 창을 막거나 보상을 다시 지급하지 않는다. 납품 기록에도 완료 도장을 남긴다.
- 작업실과 엔딩에 작업실 그림을 넣고 구입한 도구를 표시한다. 복구 노트·보조 모니터·간판의 기존 기능과 가격은 유지한다.
- 좁은 창에서는 의뢰 설명과 열기 버튼을 지도보다 먼저 보여 준다. 지도는 옆으로 움직일 수 있고 장소는 키보드로도 선택한다. 동작 줄이기 설정에서는 새 전환 효과가 멈춘다.

이번 버전에서 퍼즐 개수·보상 경제·저장 형식은 늘리거나 바꾸지 않았다. 카페 입문 3장, 후속 의뢰 18개, 선택 연습 6개, 답장 선택에 따른 세 엔딩은 [0.8의 캠페인](RELEASE-0.8-RC.md)과 같다. 자동완성, Tab, 단계별 안내와 선택 답안도 유지한다. 자동 완주는 실제 초보자가 혼자 이해했다는 증거가 아니다.

## 이미지와 영상

`public/game-art/`에는 작업실, 동네, 카페, 두 인물 초상화의 PNG 네 장이 있다. 이번 작업에서 내장 `image_gen`으로 생성했고 외부 유료 API나 다운로드한 사진을 사용하지 않았다. 동네 그림의 가짜 글자를 정리했으며 읽어야 하는 간판·버튼·상태는 코드로 표시한다. 최종 파일 경로, 프롬프트와 수정 지시는 [game-art-prompts.json](../media/game-art-prompts.json)에 보관했다. 실제 Steam 콘텐츠 설문을 작성할 때 생성 이미지 사용 내역을 근거로 검토해야 하며, 설문을 제출했다는 뜻은 아니다.

새 42초 영상은 실제 UI 조작으로 타이틀 → 빈 바탕화면 → 메시지 → 준비 → 수정·검사 → 카페 오픈 → 의뢰 지도 → 납품 → 작업실·엔딩을 촬영해 편집했다. 상태를 주입해 촬영하지 않았으며 선택 답안을 사용했다. 한·영·일 자막 가로 영상과 한국어 세로 영상을 제공한다. 촬영된 게임 UI는 한국어다. 원본, EDL, 자막과 검증 자료를 함께 보관한다.

Windows판에는 이미지 네 장을 실행 파일의 ASAR 안에 포함하여 오프라인에서 불러온다. 웹판과 같은 이미지·게임 상태를 사용한다. 배포 파일의 정확한 Git SHA와 해시는 출시 자료의 `delivery-receipt.json`으로 식별한다.

## 검증과 남은 출시 조건

검사별 실행 증거와 제한은 [QA-0.9-RC.md](QA-0.9-RC.md)에 기록한다. 이전 0.8/0.7 문서는 각 버전의 역사적 자료로 유지한다.

CODE:SHIFT는 가제다. 실제 Steam App ID, 스토어 등록, 업적·Cloud·SteamPipe, 심사, 공식 15세 등급, 실행 파일 서명은 확인하거나 완료하지 않았다. 별도 깨끗한 Windows 장비와 실제 초보자 플레이로 호환성·이해도·재미·플레이 시간을 검증해야 한다. 21,000원은 스토어에 적용된 가격이 아닌 계획 가격이다.
