# 웹 데모 전환 검증 — 2026-10-10

공개 주소는 https://code.yeolmaeapps.kr/ 이다. 사용자가 웹 데모와 게임명 투표를 먼저 공개한 뒤 Steam 출시를 준비하도록 순서를 변경했다. CODE:SHIFT는 작업명이며 네 후보 중 하나를 확정하지 않았다.

## 구현 범위

- 웹 진입점은 `demo`, 데스크톱 진입점은 `full`로 지정한다. 저장·URL·로컬 스토리지 값이나 브리지 유무로 에디션을 승격하지 않는다.
- 웹에서는 카페 3장과 OPEN까지 플레이한다. 고객 의뢰, 선택 연습, Code Lab, 최종 개인 프로젝트와 본편 엔딩은 액션·명령·경로·앱에서 제한한다. 브라우저에 내려간 JavaScript에 대한 DRM이라고 주장하지 않는다.
- 이전 전체판 저장을 잘라내지 않는다. 가져온 고객 파일·기록·보상·검사 증거를 유지하고 설정의 백업 내보내기를 제공한다. 서로 다른 사이트 주소의 저장은 자동으로 이동하지 않는다.
- 접속 국가 기반 자동 언어는 KR→한국어, JP→일본어, 나머지 유효 국가→영어다. 서버 `request.cf`가 없는 호스팅에서는 브라우저가 같은 도메인의 Cloudflare `/cdn-cgi/trace`에서 `loc`만 읽는다. 이 진단 응답의 IP와 다른 필드는 저장하거나 게임 상태에 넣지 않는다. 양쪽 모두 국가를 알 수 없으면 브라우저 언어를 사용하며 수동 선택이 우선한다. 데스크톱은 Steam·OS·브라우저 순서를 유지한다.
- 퀘스트 상단에 현재 작업과 앱·파일·다음 행동을 표시한다. 설명·진행 기록·최종 목표는 접어 두고 사용자가 연다. 실제 파일과 현재 검사 결과로 진행을 표시하며, 창을 여는 것만으로 완료 처리하지 않는다.
- 소개 페이지 3개 언어, 공유 메타데이터와 VideoGame 구조화 데이터를 실제 데모 범위에 맞췄다. 기존 홍보영상은 본편 개발 빌드 영상이며 잠긴 콘텐츠가 포함됨을 명시했다.

## 실행한 검증

`node scripts/verify-quality.mjs`: 린트 282파일 오류·경고 0, TypeScript 통과, 의존성 완화 검사 통과, 게임 271개 및 데스크톱 31개 단위 테스트 통과. 공개 환경의 Cloudflare 지역 정보 보완 테스트를 포함한다. Sites 공식 빌드 헬퍼로 production 빌드를 생성했다. 빌드의 plugin timing 및 route classification 안내는 린트 경고나 실패가 아니다.

production Worker를 로컬 Wrangler로 실행하고 실제 Chrome을 사용했다. 브라우저는 한 번에 하나만 실행했다.

- `coach.py`: KO/EN/JA 각각 새 저장에서 직접 입력·수정·검사·전달하여 세 의뢰와 OPEN 완료. 잘못된 입력 회복, 빈 값 방지, 힌트 수동 열기·닫기, 주문 응답, 데모 완료와 새로고침 복원 통과. 기존 진행을 주입해 완주한 검사로 대신하지 않았다.
- `quest-context.py`: KO/EN/JA × 1280×720·1366×768·390×844, 총 9개 조합 통과. 현재 작업과 버튼 가시성, 창 최소화·닫기·Escape·다시 열기, 힌트 수동 조작, 앱을 열어도 진행이 오르지 않음을 검사했다.
- `demo-release.py`: 서버 국가·브라우저 대체 언어 4개와 Cloudflare 국가 보완 2개 조합, 수동 설정 유지, 실제 기존 전체판 저장을 UI로 가져오기·백업 내보내기, 의뢰 잠금, 3개 언어 소개 페이지 및 canonical·공유 카드·구조화 데이터 검사. 지역 조합은 응답 모의 검사이며 해외 실접속 검사가 아니다.
- `terminal.py`: KO/EN/JA에서 파일·리다이렉션, 공백 경로 Tab 완성, `clear` 뒤 기록, Ctrl+L/C, 지원하지 않는 복합 명령의 원자적 거부 통과.
- `web-security.py`: 형식 오류·16MB 초과 저장 거부와 기존 저장 보존, 터미널 기록의 HTML 비실행, 실제 iframe 미리보기의 스크립트·URL 제거 및 CSP, 본편 앱 숨김·실행·경로·리다이렉션 차단 통과. 스크립트 표식 실행, 시험용 외부 요청과 페이지 오류는 0이었다. Code Lab은 데모에서 잠겨 있으므로 전체판의 실험실 런타임 공격 UI 검사는 이 웹 실행 범위에서 제외하고 이를 결과에 명시했다.

초기 퀘스트 테스트는 접속 국가가 브라우저 언어보다 우선하도록 바뀐 것을 반영하지 않아 실패했다. 언어를 실제 선택 UI로 지정하도록 수정하고 다시 실행했다. 완료 뒤 이전 임무 목표·예상 보상이 남는 UI도 수정했다.

기존 전체판 보안 테스트는 데모에서 숨겨진 Code Lab 앱을 열려고 해서 중단됐다. 데모에서는 해당 앱·실행 경로가 차단되고 저장·보상이 바뀌지 않는지를 확인하도록 분기했다. 경로 정규화 시험도 현재 카페 작업 디렉터리와 무관한 절대 경로로 수정한 뒤 통과했다. 실패를 통과 기록으로 덮어 해석하지 않는다.

로컬 결과·스크린샷: `output/demo-20261010/`, 정적 검사 결과: `output/quality-gate/`. 배포 영수증과 실주소 검사 결과는 `output/demo-20261010/publication.json`, `live-verification.json`으로 별도 보관한다. 이 문서 자체는 배포 성공 영수증을 대신하지 않는다.

## 참고자료 적용과 검증 한계

22개 제공 영상의 실제 화면 624개 표본을 시간순으로 확인했다. 추가 원본 크기 재확인과 끝부분 표본은 각 참고 문서에 기록했다. 전 영상을 연속 재생하거나 모든 프레임·음성을 시청했다는 의미는 아니다. 관찰한 지속 목표·결과 확인·전달 흐름은 우리 카페의 현재 작업과 파일 변화 중심으로 적용했다. AI Tech Studio의 상태 기반 단계·판정 진행률 아이디어와 MIT 출처를 참고했으며 타 게임의 화면이나 에셋을 복제하지 않았다.
