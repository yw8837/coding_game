# 0.12 RC — 고객의 문제를 직접 실행하는 게임

2026-10-10. 기준 커밋 445d474. 사용자는 전체 개선·QA·배포·패키징과 가격 재책정을 요청했다. 기본 바탕화면, 실제 파일/터미널, 기존 저장과 수동 힌트 정책을 유지한다.

## 수용 기준

1. 카페 뒤 18개 의뢰도 첫 장부터 직접 입력한다. 정답 선택은 기본 화면에서 제거한다. 선택 예시는 사용자가 도움을 열었을 때 초안을 채울 뿐 저장·검사·완료를 대신하지 않는다.
2. 의뢰마다 고객 상황을 골라 현재 파일의 결과를 실행하는 화면을 제공한다. 영수증, 접수, 목록, 시간표 등 서로 다른 결과를 구분한다. 성공 애니메이션은 실제 평가 결과에만 따른다. 파일을 수정하면 이전 실행 결과가 오래됐음을 명시한다. 실험 자체로 보상이나 완료를 지급하지 않는다.
3. 직접 작업 설정은 후반 코드 편집과 최종 프로젝트에도 적용한다. 도움말은 기본으로 닫혀 있고 오류가 열지 않는다. 초보자를 위한 현재 목표와 다음 행동은 숨기지 않는다.
4. 카페→동네 의뢰→내 첫 출시의 연결과 수락/저장/검사/전달 피드백을 점검한다. 잘못된 입력, 저장 거절, 오래된 검사, 중복 보상, 저장 호환성의 실제 결함을 수정한다.
5. 한·영·일, 1440px/390px, 키보드, 빈 입력/실패/수정 후 재실행, 전체 캠페인·엔딩과 Windows 저장을 검증한다. 0.12 Windows RC와 웹판은 동일 소스로 만든다.
6. 공식 Steam 한국 가격을 조사해 일회성 구매 권장가를 제시하고 현행 계획 문서를 갱신한다. 외부 스토어 실제 가격 설정은 수행하지 않는다.

## 소유권과 순서

- 메인: 후반 고객 상황 실행 화면, CareerView 통합, 가격 문서 통합, 브라우저 QA·통합·빌드·배포·패키징.
- novice_setup: 초보 흐름 감사 후 CareerLearning/ReleaseProject/ReleaseLearning 및 필요한 CafeCoach 개선. 구현 전 변경 범위 전달.
- reference_design: 코어 상태·저장·보안 감사 후 확인된 결함만 수정. 메인과 파일 소유권 조정.
- launch_research: 공식 가격 조사 및 docs/pricing-2026-10.md.
- 구현 완료 후 기능/보안/코드 관점 교차 검토. 브라우저와 무거운 빌드는 한 번에 하나만 실행.

## 확인 범위의 한계

자동 완주는 재미·학습 효과·플레이타임의 실측이 아니다. 기존 다른 게임 AppID 5336990은 사용하지 않는다. Steam 계정 내 신규 게임 등록·결제·심사와 코드 서명, 별도 장비·실제 참가자 플레이 검증은 자동 완료로 주장하지 않는다. 기존 공개 영상은 실제 게임 장면으로 유지하며 이번 변경과 어긋나는 설명은 갱신한다.
