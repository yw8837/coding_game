# 0.13.2 RC — 구매한 도구의 효과와 현재 플레이 영상

`find-skills`로 필요한 방법을 검색·검토한 뒤 실제 결함과 낡은 자료를 갱신했다. [검색과 적용 기록](reviews/skill-actions-2026-10-10.md), [경제 검토](reviews/economy-2026-10-10.md), [QA](QA-0.13.2-RC.md)를 함께 확인한다.

- 600 cr 보조 모니터가 단계별 편집·JavaScript·전체 설정 파일 편집 모두에서 저장된 파일의 실행 결과를 보여 준다. 좁은 창에서는 숨기지 않고 아래에 배치한다. 저장하지 않은 JS는 실행 결과에 반영하지 않는다.
- 가격·보상·필수 의뢰 수는 유지한다. 검토상 돈이 부족해 반복해야 하는 구간이나 정상 action의 무한 보상은 발견하지 못했다. 후반에 쓸 돈이 남는 것의 재미 영향은 사람에게 확인한다.
- 오프라인 플레이테스트 도구는 초보자·경험자·본인 기록을 분리하고 보상 이해·사용처·반복/선택·다른 해법의 선택 메모를 지원한다. 이전 v1 기록과 CSV22열을 유지한다. 실제 참가자 결과는 아직 없다.
- 파일 가져오기 대기 중 작성한 관찰 메모와 새 세션을 최신 기록에 병합해 보존한다. Windows 빌드 정보도 루트 패키지 버전을 읽어 오래된 버전 표시가 남지 않도록 한다.
- 홍보영상은 현재 빌드의 실제 동작을 촬영했다. 오류→코드→결과→보상→도구→의뢰 선택→내 포트폴리오 배포를 30초로 편집한다. 한국어 UI와 세 언어 타이포그래피, 밝은128BPM 음악·편집 효과음을 사용한다. UI-earned 카페 저장 가져오기·중간 생략·속도 편집을 밝힌다. 과거 영상은 보존한다.

Windows 오프라인 RC이며 새 Steam AppID·실제 Steam 런타임·심사, 코드 서명·다른 PC 최소 사양, 사람의 재미·학습·청음과 원어민 감수는 여전히 별도 검증이다. 기존 AppID5336990은 다른 게임이므로 사용하지 않는다. 전체 웹판은 실제 Steam 출시 전까지 유지한다.
