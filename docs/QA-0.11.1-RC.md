# 0.11.1 RC 검증 기록

2026-10-10. 버전 `0.11.1-rc.0`. C: 원본에서 검사하며 브라우저·영상 렌더·네이티브 빌드는 한 번에 하나씩 실행한다.

## 게임과 UI

- 게임·데스크톱 단위 검사 **225/225 통과**, 실패·취소·스킵 0개. 직접 편집의 실제 파일 반영, 잘못된 값과 HTML 이스케이프, 60,000자 초과 저장 거절, 구매 차감과 기존 저장 호환, 현재 창 가시성, 효과음 예약 취소를 포함한다.
- 최종 변경 후 TypeScript 검사 통과. 전체 ESLint는 238개 파일에서 오류 0개·경고 69개.
- 튜토리얼: KO/EN/JA 각각 새 저장에서 카페 3장, 손님 3명, 실제 가상 API 요청과 카페 오픈까지 통과. 빈 입력 차단, 입력 그대로 파일 반영, 수동 힌트 열기/닫기, 오류 뒤 자동 힌트 없음, 다시 고쳐 진행을 확인했다. 페이지 오류 0개.
- 퀘스트·메시지: 최종 변경 후 세 언어 × 1440/390px의 6조합 통과. 보이는 앱의 반복 열기 버튼 제거, 최소화/닫기/다른 창에 가림 후 이동 안내 복원, 읽은 welcome 메시지 알림 제거를 확인했다. 제목줄만 남거나 좁은 가장자리만 드러난 창은 작업 가능한 창으로 보지 않는다. 다른 URL이나 직접 편집할 파일로 이동해야 할 때는 이동 버튼을 유지하며, 이 조건을 단위 검사와 Windows 전체 진행에서 확인했다.
- 배경: 세 언어 × 1440/390px의 6조합 통과. 네 실제 이미지 로딩, 카드·페이지 가로 넘침 없음, 현지화된 구매 알림, 잔액 부족 차단, 무료 재적용을 확인했다. 별도 촬영 검사에서는 오피스텔 180cr, 해변·정원 각 90cr 차감과 새로고침 후 선택 복원을 확인했다.
- 기존 지갑/도구 상점 회귀 통과. 3개 도구 구입, 중복 구입 차단과 저장 복원을 확인했다.
- 소개 페이지의 세 언어 30초 영상 재생·탐색, 메타데이터, 빈 바탕화면 시작과 터미널 help 확인을 통과했다.

저장 거절인데도 성공 설명이 나오는 결함을 소스 검토에서 발견해 수정하고 재검토했다. 입력 검증이 파일 변경 액션만 만들고, 보상은 최신 검사·배포 증거를 요구함을 확인했다. 이를 게임 전체에 대한 무취약성 보장으로 표현하지 않는다. 이전 의존성 감사의 생산·데스크톱 0건, 개발/빌드 braces High 1건은 [보안 기록](security/README.md)에 유지한다. 이번에는 의존성을 변경하지 않았다.

## 영상

30초·900프레임·30fps, H.264 yuv420p / AAC stereo 48kHz. KO/EN/JA 가로 1920×1080와 KO 세로 1080×1920 네 파일을 각각 전체 디코딩하고 크기·코덱·음량·프레임 수를 검사했다. 최종 인코딩 음량은 약 −15.96 LUFS / −2.87 dBTP다.

전체 장면 요약, 실제 코드 수정·계산·주문·보상·출시 화면과 자막 진입 초기 프레임을 확인했다. 긴 영어 자막이 게임 패널을 침범하던 경계와 카페 오픈 컷에 이전 보상창이 잠깐 남던 범위를 조정했다. 세로판은 일부 장면을 실제 결과 영역으로 다시 잡았다. 음악은 Realizer / Kevin MacLeod / CC BY 4.0이며 별도 크레딧, 영상 메타데이터와 소개 페이지에 표시한다. 실제 사람의 전체 영상 청취는 아직 하지 않았다.

## Windows와 전달

- 최종 소스로 Windows 렌더러 빌드 성공. JavaScript 번들 약 1.24 MB이며 크기 경고는 남아 있다.
- Electron 실제 UI로 카페 3장, 동네 의뢰 18개, 최종 앱 빌드·출시·균형 엔딩까지 통과. Code Lab, 가상 파일 편집과 터미널 실행, 달력, 종료 저장, 재실행, 백업 가져오기/내보내기, 잘못된 주 저장의 백업 복원을 확인했다. 페이지 오류 0개.
- QA 패키지 실행에서 일본어 선택 유지, 의뢰 수락 저장, 종료 후 이어하기, 시작 시 빈 바탕화면, Node 접근 차단을 확인했다. 새 블루 배경이 패키지 화면에 렌더링됨도 확인했다.
- 배포용 Windows x64 오프라인 패키지 생성 및 무결성 검사 통과. QA 플래그 false, Steam AppID null, Steam 모듈 미포함, 실행 제한 fuse와 라이선스 파일을 확인했다. 검사한 QA 패키지와 게임 파일 22개가 같고, 이미지 8개의 포함 내용과 SHA-256이 원본과 일치한다.
- ZIP CRC·SHA-256과 실제 사이트 배포 식별자는 전달 폴더의 영수증과 무결성 목록에 기록한다.

## 증거

- `output/0.11-direct-coach/`: 새 튜토리얼, 힌트 상태, 390px 캡처와 보고서.
- `output/0.11-qa/quest-context/`: 6조합 퀘스트·알림 회귀.
- `output/0.11-wallpapers/`: 배경 상점 언어·크기별 보고서와 화면.
- `output/trailer-rebuild/`: 실제 촬영, 시간 정렬 증거, 최종 MP4와 SHA-256·음량 검사, 자막 초기 프레임.
- `output/steam-qa/`, `output/art-qa/`: 네이티브 실행/저장 및 패키지 무결성 검사.
- 전달 폴더 `delivery-receipt.json`, `integrity-manifest.json`, `qa/zip-report.json`: 실제 배포·커밋·ZIP 식별자와 해시.

실제 초보자의 재미·이해도·학습 성과나 플레이타임은 자동화 검사로 입증하지 않는다. 서명, 별도 Windows 장비 검증, 이 게임의 Steam 등록·연동·업로드·심사는 남아 있다. 기존 다른 게임 AppID 5336990은 사용하지 않았다. 이전 RC와 사용자 저장은 보존한다.
