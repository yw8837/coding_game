CODE:SHIFT 0.13.2 · 오프라인 관찰 도구

플레이를 보고,
막힌 곳을 남기세요.

처음 3분은 조작이나 답을 알려주지 않습니다. 참가자는 언제든 쉬거나 그만둘 수 있습니다.

시작 전에

  1. 기존 플레이 저장은 게임 설정에서 먼저 백업 내보내기. 새 브라우저 프로필이나 별도 Windows 테스트 계정을 사용하세요.
  2. 사용자가 먼저 20~30분 플레이한 뒤, 서로 독립적인 초보자 3~5명과 별도의 경험자 2~3명에게 같은 버전을 보여 주세요. 초보자는 “함께 배우기”, 경험자는 “직접 작업”으로 진행하고 설정을 메모하세요.
  3. 실명·나이·연락처는 수집하지 않습니다. 녹화·화면 캡처·음성 기록은 각각 별도 동의를 받은 경우에만 진행하세요.

기록은 이 브라우저에만 저장됩니다. 파일 주소의 저장이 막힌 브라우저에서는 메모리로만 유지됩니다. 항상 JSON을 내보내 보관하세요. 게임 저장에는 접근하지 않습니다.

진행 안내문 열기

아직 실제 관찰 결과가 없습니다.

참가자와 환경

체크하지 않은 상태에서는 녹화·캡처·음성 기록을 하지 않습니다. 이 도구는 직접 녹화하지 않습니다.

진행 중 관찰

모든 항목은 미관찰로 시작합니다. 완료 여부를 실제로 보지 못했다면 그대로 남기세요. 처음부터 보이는 기본 안내는 게임 흐름입니다. 추가 힌트·선택 도움을 사용했다면 그 사실을 따로 적습니다.

선택 관찰은 기존 근거·전체 메모에 행동과 원문으로 남깁니다. 해결로 생긴 변화와 보상을 이해했는지, 보상 사용처를 발견·사용했는지, 다음 의뢰 선택·반복에 관해 무엇을 말했는지 관찰하세요. 경험자는 도달한 지원 의뢰에서 다른 해법을 시도했는지도 기록합니다. 도달하지 않은 항목은 미관찰이며 실패로 채점하지 않습니다.

끝난 뒤 참가자에게 묻기

정답을 말해 주기 전에 답변을 원문에 가깝게 적으세요. 빈칸은 미응답입니다.

이 세 문항은 간단한 자체 문항이며 검증된 심리 척도가 아닙니다. 합산 점수나 학습 성공률을 만들지 않습니다.

입력 시 자동으로 로컬 저장을 시도합니다. 내보내기 파일을 별도로 보관하세요.

짧은 진행 순서

  1. 2분: 목적·중단 권리·별도 기록 동의. 조작법과 답은 설명하지 않습니다.
  2. 15~20분: 빈 바탕화면 → 메시지 → 고장 관찰 → 이름·너비·연산자 직접 수정 → 결과 확인 → 선택 의뢰. 실제로 도달한 만큼만 관찰합니다.
  3. 3~5분: 새 상황 과제와 짧은 질문. 전체는 20~30분 안에 마칩니다.

새 상황 과제: 참가자가 만났던 것과 다른 숫자나 조건을 제시하고, 어떤 값을 바꾸고 결과가 어떻게 될지 먼저 설명하게 하세요. 원래 답이나 해법을 제공하지 않습니다. 도달하지 못한 개념은 시험하지 않고 미관찰로 남깁니다.
