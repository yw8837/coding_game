# Steam candidate implementation

User approved proceeding to final completion on 2026-10-09. Final target: Steam PC, KRW21,000, KO/EN/JA, final title still reserved for user selection. The original 0.7 release remains a valid historical artifact.

1. Automatic locale with explicit preference and native Steam/OS fallback (locale worker).
2. Eighteen authored contracts after the three-case cafe introduction, grouped into three acts, actual file evaluation and counterexamples (content worker). Main integrates canonical virtual filesystem, inspect/edit/test/deliver proof, one-time pay, upgrade spending, client choices and concluding outcomes.
3. Offline Windows desktop runtime with restricted bridge, atomic saves/recovery, bounded native operations and optional real Steam initialization (packaging worker). Main integrates startup/save/close and achievement events.
4. UI-only normal and adversarial campaign tests, locale/save migration/stale proof/reward/upgrade tests, desktop offline/package/security checks. One browser/build/render at a time.
5. Update capture and honest product copy after verified contents. Commit/push/mirror, public browser build and deliver native package. Preserve production version7 rollback.

Steam App ID/partner onboarding was requested asynchronously. Never use a fake shipped App ID or claim Steam account/Cloud/achievement/store verification before a real partner configuration exists. No price submission, payment, store publication or final rename is performed without concrete user decisions/access. Missing Steam account does not prevent building and testing offline deliverables.

Completion means implemented, exercised and delivered artifacts with explicit evidence. Eighteen short contracts do not by themselves establish six-to-eight hours of play or an independently validated KRW21,000 value. Those claims require actual novice playtesting. Unknown external store gates remain visible rather than being marked complete.
