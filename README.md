# CODE:SHIFT — 모노 카페 이야기 0.7

CODE:SHIFT는 작업명입니다. 코딩을 처음 접하는 플레이어가 카페의 온라인 오픈을 돕는 세 장의 브라우저 게임입니다. 본편 엔딩 뒤에도 작업실을 이용할 수 있고, 여섯 개의 선택 연습 의뢰를 별도로 풀 수 있습니다.

최종 제품은 **Steam PC판, 한국 판매 기준가 21,000원**으로 준비합니다. 제목 후보, 자동 언어 정책과 정식판 확장 목표는 [Steam 정식판 계획](docs/STEAM-RELEASE-PLAN.md)에 정리했습니다. 아래 내용은 현재 0.7 브라우저판의 구현과 검증 기록입니다.

Start → 아무 앱도 열리지 않은 바탕화면 → 작업 표시줄·시작 메뉴로 앱 열기 → 메시지 수락 → 프로젝트 준비 → 고장 관찰·파일 수정·검사·전달 → 세 장 완료 → OPEN 엔딩으로 이어집니다. Windows 스타일 화면 안에서 Linux 개발 터미널을 시뮬레이션합니다. 명령, 파일, Git, 서버, API는 하나의 게임 상태를 사용합니다.

## 실행

Node 22.13 이상과 `package.json`에 고정된 pnpm을 사용합니다. 아래 명령은 개발·검사·빌드 방법입니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
node --test lib/game/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
pnpm build
```

pnpm 링크를 지원하는 파일시스템에 체크아웃을 두세요. 이 작업의 실행 위치는 `C:\codex-workspaces\codeshift-game`입니다. 사용자의 D: exFAT 볼륨에는 pnpm 링크 제약이 있습니다.

## 플레이

- 타이틀에서 Start 또는 Continue를 누르면 빈 바탕화면이 열립니다. 왼쪽 바로가기, 작업 표시줄, 검색 가능한 시작 메뉴로 앱을 엽니다.
- 앱 창을 동시에 열어 겹치기·이동·크기 변경·좌우 배치·최대화·최소화·닫기·다시 열기를 할 수 있습니다. 작은 화면에서는 활성 앱을 표시합니다.
- 현재 목표는 앱 밖에 남습니다. 내 PC의 프로젝트 복사 → 도구 준비 → 미리보기 시작 버튼으로 준비하거나, 터미널에 직접 명령을 입력할 수 있습니다.
- 본편은 HTML/CSS, 합계 연산, 서버 주소와 주문 보관 설정을 직접 고치는 세 의뢰입니다. 검사 결과와 API 응답을 보고 수정본을 기록·전송·검토·배포합니다.
- 여섯 연습 의뢰는 짧은 규칙과 여러 입력/예상 결과를 보여 줍니다. 틀린 규칙에는 실패한 입력과 실제 결과가 표시됩니다. 첫 성공만 보상을 지급하며 다시 풀 수 있습니다.
- 한국어/English/日本語, 효과음 설정, 에디터 자동완성·실행 취소, 터미널 Tab·명령 기록, 메모장을 지원합니다. 시간 제한·실패로 인한 자금 차감·힌트 페널티는 없습니다.

게임 진행과 파일은 현재 브라우저의 localStorage에 자동 저장됩니다. 앱을 닫거나 최소화해도 같은 데스크톱 세션의 입력 초안은 유지됩니다. 창 배치와 모든 앱의 임시 입력을 새로고침 뒤까지 보존하는 것은 아닙니다. 저장 키 `codeshift-intro-demo-v1`은 이전 진행과의 호환을 위해 유지하며, 누락된 새 필드에 기본값을 채웁니다. 별도 키 `codeshift-save-v1`의 자동 이전은 제공하지 않습니다.

## 확인한 결과

2026-10-09의 `output/pc-qa` 기록에서 단위 검사 55/55 통과, 전체 캠페인과 OPEN 엔딩 완료, 영어·일본어 첫 장과 연습·저장 복원·가로 넘침 검사 성공을 확인했습니다. 최종 소스의 TypeScript 검사 종료 코드도 0입니다. 캠페인만 완료한 결과는 1,720 cr / 560 XP이며, 연습 보상과 보너스·꾸미기 지출을 포함하지 않습니다.

한국어·영어·일본어 소개 페이지의 메타데이터와 1920×1080, 42초 실제 게임 영상 재생도 확인했습니다. 자세한 증거와 한계는 [게임플레이 검증](docs/gameplay-verification.md)에 있습니다. 자동 검사 결과는 실제 초보자의 이해도·재미 평가를 대신하지 않습니다.

Sites 배포는 기존 `.openai/hosting.json` 프로젝트를 사용합니다. 0.7 공개 완료 판정은 메인 작업자가 생성하는 `D:/코딩게임/출시자료/0.7/verification/release-receipt.json`의 빌드·배포 기록으로 확인합니다. 개발용 `output` 기록과 플레이어 저장은 배포에 포함하지 않습니다.

## 범위

모든 명령과 서버는 가상 환경입니다. 플레이어의 실제 셸·파일시스템·네트워크를 조작하지 않습니다. JavaScript의 제한된 표현식과 제공된 Python 템플릿 설정을 해석하며 범용 실행 환경은 아닙니다. NPC 문구는 작성된 대사이고 외부 AI/LLM을 호출하지 않습니다. 공식 15세 이용 등급 인증, 실제 초보자 사용성 연구, Steam·모바일 스토어 패키징과 출시 승인은 이번 브라우저 버전의 결과에 포함되지 않습니다.
