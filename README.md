# CODE:SHIFT — PC 시뮬레이터 0.12 RC

CODE:SHIFT는 작업명입니다. 코딩을 처음 접하는 플레이어가 카페의 온라인 오픈을 돕는 게임입니다. 카페 입문 3장 뒤에 고객 의뢰 18개와 선택에 따른 세 가지 결말이 이어집니다. 여섯 개의 규칙 연습과 12개 JavaScript 함수 수리 의뢰, 각 의뢰의 반례 도전도 있습니다. 브라우저판과 오프라인 Windows 실행판은 같은 게임을 사용합니다.

최종 제품은 **Steam PC판, 한국 판매 권장가 11,000원**으로 준비합니다. 제목 후보, 자동 언어 정책과 정식판 확장 목표는 [Steam 정식판 계획](docs/STEAM-RELEASE-PLAN.md)에 정리했습니다. 현재 구현·검증 범위는 [0.12 RC 변경점](docs/RELEASE-0.12-RC.md)과 [0.12 QA](docs/QA-0.12-RC.md)를 확인하세요. 가격 비교와 출시 할인안은 [가격 근거](docs/pricing-2026-10.md)를 참고하세요. 과거 Steamworks 점검에서 앱 크레딧 0개를 확인했으며 현재 잔액을 다시 조회한 것은 아닙니다. 이 게임의 등록·심사·출시는 아직 진행되지 않았습니다.

Start → 아무 앱도 열리지 않은 바탕화면 → 작업 표시줄·시작 메뉴로 앱 열기 → 메시지 수락 → 프로젝트 준비 → 고장 관찰·파일 수정·검사·전달 → 세 장 완료 → OPEN → 독립 작업실의 18개 의뢰 → 내 프로젝트 1.0.0 배포 → 마지막 편지로 이어집니다. Windows 스타일 화면 안에서 Linux 개발 터미널을 시뮬레이션합니다. 명령, 파일, Git, 서버, API는 하나의 게임 상태를 사용합니다.

## 실행

Node 22.13 이상과 `package.json`에 고정된 pnpm을 사용합니다. 아래 명령은 개발·검사·빌드 방법입니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
node --test lib/game/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
pnpm build
```

pnpm 링크를 지원하는 파일시스템에 체크아웃을 두세요. 이 작업의 실행 위치는 `C:\codex-workspaces\codeshift-game`입니다. 사용자의 D: exFAT 볼륨에는 pnpm 링크 제약이 있습니다.

## 플레이

기본 **함께 배우기**는 간판 이름 직접 입력 → 너비 슬라이더 조절 → 계산 연산자 직접 입력 → 메뉴 주소 입력 → 주문 보관 설정으로 이어집니다. 변경을 파일에 저장하고 화면·손님 주문·API 응답으로 결과를 확인합니다. 힌트는 플레이어가 직접 열며 자동으로 답을 선택하지 않습니다. 설정에서 **직접 작업**으로 전환하거나 앱을 직접 열어 터미널과 에디터로 해결할 수도 있습니다. 18개 의뢰 뒤 **동네 도움판 1.0.0**을 검사·기록·배포하면 엔딩 편지가 열립니다. 기존 엔딩 저장은 그대로 보존하고 새 최종 프로젝트를 추가로 진행합니다.

- 타이틀에서 Start 또는 Continue를 누르면 빈 바탕화면이 열립니다. 왼쪽 바로가기, 작업 표시줄, 검색 가능한 시작 메뉴로 앱을 엽니다.
- 작업표시줄은 시작·검색 / 앱 / 우측 시스템 트레이로 나뉩니다. 실제 시계·날짜는 좁은 화면에서도 보이고, 달력에는 최근 실행한 명령이 표시됩니다. 시작 메뉴의 최근 파일로 실제 편집한 가상 파일을 다시 엽니다.
- 앱 창을 동시에 열어 겹치기·이동·크기 변경·좌우 배치·최대화·최소화·닫기·다시 열기를 할 수 있습니다. 작은 화면에서는 활성 앱을 표시합니다.
- 현재 목표는 앱 밖에 남습니다. 내 PC의 프로젝트 복사 → 도구 준비 → 미리보기 시작 버튼으로 준비하거나, 터미널에 직접 명령을 입력할 수 있습니다.
- 카페 입문은 HTML/CSS, 합계 연산, 서버 주소와 주문 보관 설정을 직접 고치는 세 의뢰입니다. 검사 결과와 API 응답을 보고 수정본을 기록·전송·검토·배포합니다.
- 후속 18개 의뢰는 JSON·CSV·제한된 HTML/CSS·로그와 시간 설정을 직접 고치는 짧은 퍼즐입니다. 수락 → 문제 확인 → 편집 → 검사 → 답장과 전달 순서로 진행합니다. 수입으로 복구 노트·보조 모니터·작업실 간판을 구입합니다.
- 바탕화면 배경은 무료 기본 블루, 햇살 해변 90cr, 초록 정원 90cr, 오피스텔 작업실 180cr의 네 종류입니다. 실제 배경 이미지가 바뀌며, 소유한 배경은 추가 차감 없이 다시 적용할 수 있습니다.
- 의뢰 지도에서 고객의 장소와 문제를 고릅니다. 전달한 장소에 도장이 남고 다음 장이 열립니다. 작업실·동네·카페·인물 이미지가 실제 진행 상태와 연결되며, 카페 오픈과 납품에는 짧은 시청각 피드백이 있습니다.
- 코드 의뢰의 파일 준비 뒤에는 `code receipt.js`, `node run.cjs receipt.js receipt.input.json`, `node --test receipt.test.cjs`를 직접 입력해 같은 가상 파일을 편집·실행·검사합니다.
- 코드 의뢰 12개는 제한된 JavaScript 해석기로 실제 함수를 실행합니다. 조건·반복·배열·데이터 정리부터 API 응답 규칙·멱등성·원자성·캐시 만료까지 연습합니다. 전체 예제는 선택사항이며 보상은 차감하지 않습니다. 후속 반례 도전과 새 입력 재검사를 지원합니다.
- 여섯 연습 의뢰는 짧은 규칙과 여러 입력/예상 결과를 보여 줍니다. 틀린 규칙에는 실패한 입력과 실제 결과가 표시됩니다. 첫 성공만 보상을 지급하며 다시 풀 수 있습니다.
- 한국어/English/日本語, 효과음 설정, 에디터 자동완성·실행 취소, 터미널 Tab·명령 기록, 메모장을 지원합니다. 시간 제한·실패로 인한 자금 차감·힌트 페널티는 없습니다.

브라우저판은 localStorage에, Windows판은 사용자 폴더의 파일에 자동 저장됩니다. 설정에서 백업을 내보내거나 가져올 수 있습니다. 설치판 제작·오프라인 실행·저장 경로는 [desktop-release.md](docs/desktop-release.md)에 있습니다. 앱을 닫거나 최소화해도 같은 데스크톱 세션의 입력 초안은 유지됩니다. 창 배치와 모든 앱의 임시 입력을 새로고침 뒤까지 보존하는 것은 아닙니다. 저장 키 `codeshift-intro-demo-v1`은 이전 진행과의 호환을 위해 유지하며, 누락된 새 필드에 기본값을 채웁니다. 별도 키 `codeshift-save-v1`의 자동 이전은 제공하지 않습니다.

## 확인한 결과

카페 3장 정상 흐름, 세 언어의 후속 18개 의뢰 및 엔딩, 오류 판정·보상 중복·저장 복구를 검사합니다. 테스트 명령과 실제 실행 결과는 [QA 기록](docs/QA-0.12-RC.md)에 보관합니다. 이전 버전의 QA 문서는 역사적 기록이며 최신 검사를 대신하지 않습니다.

[실제 플레이 영상 제작](media/trailer/README.md)의 최신 결과는 `output/trailer-rebuild/final/`에 있습니다. 30초 한국어·영어·일본어 가로 영상과 한국어 세로 영상이 코드 수정, 손님 응대, 주문 보관, 보상과 구매, 동네 의뢰, 첫 프로그램 배포를 보여 줍니다. 한국어 게임 UI를 새로 자동 촬영했고, 후반은 기존 UI 플레이로 얻은 18개 의뢰 완료 저장을 화면에서 가져와 촬영했습니다. Code Lab 12개는 영상에 포함되지 않습니다. 음악은 Kevin MacLeod의 **Realizer**, CC BY 4.0이며 함께 제공하는 `ATTRIBUTION.txt`에 출처와 편집 내용을 기재했습니다. 기존 42초 자료는 `output/archive/trailers-before-rebuild-20261009/trailer-0.10/`에 보존합니다.

위 영상의 촬영 버전은 **0.11.1**입니다. 이번 0.12의 후반 고객 상황 화면과 직접 입력 학습 변경을 새로 촬영한 영상은 아닙니다.

게임 일러스트와 네 종류의 바탕화면 PNG는 `public/game-art/`에 있습니다. 기존 게임 일러스트의 경로와 생성 프롬프트는 [이미지 제작 기록](media/game-art-prompts.json)에 보관합니다.

## 범위

터미널·Git·서버·API는 가상 환경이며 플레이어 코드를 호스트에서 실행하지 않습니다. 제공된 제한 형식을 해석하는 퍼즐이며 범용 개발 도구는 아닙니다. NPC는 작성된 대사를 사용하고 외부 AI/LLM을 호출하지 않습니다.

실제 초보자 플레이 시간·이해도·재미는 자동 완주만으로 검증할 수 없습니다. 공식 15세 등급, Steam 계정/업적/Cloud/스토어 심사, 실행 파일 서명과 깨끗한 별도 Windows 장비 검증은 완료로 주장하지 않습니다. 11,000원은 Steam 한국 판매 계획 가격이며 스토어에 적용한 기록은 아닙니다.
